## 3. function-call与调用链

六项均可从`GET /api/v1/tools`动态发现，并通过：

- `POST /api/v1/tools/{function.name}/call`直接function call；
- `POST /api/v1/experiments/run`的`forced`模式逐项强制调用；
- 同一实验接口的确定性关键词`autonomous`模式逐项召回。

E021专项集成测试执行了真实三段链：

```text
B008(2C + O₂ → 2CO, 1000 K) ─┐
                               ├→ E021(C + CO₂ → 2CO)
B008(C + O₂ → CO₂, 1000 K)  ─┘
```

测试保留两条B008执行编号与E021自身执行编号，并验证E021返回的上游编号、Hess差值和`RTln(Q/K)`恒等式。前端无需硬编码适配，新工具随动态接口自动出现。

隔离外部provider强制调用用例已写入`Tools/benchmarks/llm_tool_call_cases_p1_w10.json`，每项单独提供唯一function及结果断言。该文件是冒烟测试夹具，不是正式研究数据集。本波未调用外部大模型API，不能把本地forced路由结果表述为外部模型实测。

## 7. 已知限制与下一批候选

1. A011只接受唯一一维正零空间，不替用户从多自由度反应网络选择附加约束；
2. C011只计算定义式，不选择具体Nu/Sh关联式；下一候选可评审C012，但必须先固定关联式与适用域；
3. T003不组合温变物性、辐射或Bi>0.1空间温度场；T004不含辐射等效非线性热阻；
4. D023不做多合金成本/库存优化；D019可作为后续候选，但需要先定义连续或混合整数优化契约；
5. E021由调用方保证两次B008来自同温同标准态；若未来要服务器端强校验执行记录，需要先设计持久化执行追溯契约；
6. 后续继续优先采用替换清单中的无现场数据工具；A009/A010等候选必须先完成独立蓝图，不自动实施。
