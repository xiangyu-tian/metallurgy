## 2. 实现内容

### 2.1 F005到F006调用链

F005的 `time_history` 以向后兼容方式新增 `center_solid_fraction`，既有字段未删除或改名。真实链路为：

```text
F005实际HTTP执行
  └─ execution_id
  └─ time_history[].time_s / center_solid_fraction
       ↓
F006实际HTTP执行
  └─ 首次阈值交点
  └─ z = casting_speed × time
  └─ 设备出口固相率和设备内外状态
```

F006不在内部隐藏调用F005，调用者必须显式传递F005执行ID、拉速、终点固相率阈值、中心固相率曲线和批准设备配置ID，因此两层执行身份和两层数据来源均可审计。

### 2.2 算法

F006寻找首个满足 `fs_center(t) >= fs_threshold` 的采样点。阈值位于相邻点之间时执行分段线性插值：

```text
t* = t0 + (fs_threshold - fs0) × (t1 - t0) / (fs1 - fs0)
z* = casting_speed × t*
```

输出包括终点时间和位置、左右插值点、时间/位置分辨率、包围位置区间、有效冶金长度、出口时间、出口中心固相率、设备状态、F005执行ID、设备配置版本和算法版本。分辨率是数值离散区间，不冒充统计置信区间。

曲线必须含2至2001点；时间有限、非负且严格递增；固相率有限、位于 `[0,1]` 且单调不减。曲线必须跨越终点阈值并覆盖设备出口时刻。拉速必须落在设备配置批准范围内。

### 2.3 失败关闭

- 配置不存在或未批准：`MISSING_DATA`；
- 拉速超批准范围：`OUT_OF_DOMAIN`；
- 时间/固相率字段非法或曲线非单调：`INVALID_INPUT`；
- 曲线未达到阈值：`MODEL_NOT_APPLICABLE`；
- 曲线未覆盖设备出口：`MISSING_DATA`；
- 合成数学配置请求 `engineering`：`MODEL_NOT_APPLICABLE`；
- 终点超过设备长度：成功返回 `beyond_machine_exit` 并给出风险警告，不伪造成设备内结果。
