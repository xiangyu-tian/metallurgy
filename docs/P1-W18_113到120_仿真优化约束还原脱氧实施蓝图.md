## 2. 七项工具契约

### G005 — OpenFOAM 参数化案例生成

- 科学作用：把规则长方体几何、网格、扩散率和定值/零梯度边界转换为 OpenFOAM v13 `laplacianFoam` 的完整案例；既可只返回清单，也可生成真实目录及确定性 ZIP。
- 输入：安全案例名；长宽厚 `[m]`；三向单元数 `[1]`；标量扩散率 `[m²/s]`；左右边界值 `[K]`；求解终止时间与写出间隔 `[s]`；案例产出模式。
- 输出：求解器/版本、单元数、网格尺度、文件路径—内容映射、逐文件与总清单 SHA-256、案例目录/清单/ZIP 路径、ZIP SHA-256、回读及结构校验、执行步骤。
- 适用域：单块正交六面体、x 向定值边界、其余面零梯度；单元数不超过 2,000,000；落盘仅限项目 `outputs/openfoam_cases/`，不执行或声称已执行 OpenFOAM。
- 失败：非法案例名、非正几何/扩散率、网格或时间参数越界、非有限值、模板完整性失败、固定目录不可写、落盘/ZIP 回读不一致、同名异内容冲突。
- 独立验证：8 顶点/6 面/右手块；单元数乘积；必需目录结构及花括号闭合；相同输入清单与 ZIP 哈希恒定；边界名一致；目录及 ZIP 逐字节回读；同名同内容幂等复用、同名异内容拒绝覆盖。
- 关系：依赖 G001 的网格质量概念；与 G003 的内部 PDE 解重叠但输出粒度不同；为 G006 提供可批量生成的案例。
- 依据：[OpenFOAM v13 案例结构](https://doc.cfd.direct/openfoam/user-guide-v13/case-file-structure)、[blockMesh 说明](https://doc.cfd.direct/openfoam/user-guide-v13/blockmesh)、[laplacianFoam 源码说明](https://cpp.openfoam.org/v13/dir_2eb0e56db9e71973c1240c4d553b433f.html)。

### G006 — 注册工具参数化仿真批处理

- 科学作用：对一个完全准入的注册工具执行确定性笛卡尔参数网格，逐运行返回状态、结果和失败原因。
- 输入：目标模型码、基础参数、1–4 个数值路径及各自取值、最大运行数、失败重试次数、是否允许边界警告。
- 输出：网格维数、计划/完成/成功/失败计数、按稳定顺序排列的逐运行输入/输出/错误、批次摘要哈希。
- 适用域：最多 256 次运行、每轴 2–16 个值、最多重试 2 次；禁止调用自身及 G009–G012，避免递归编排。
- 失败：目标不存在或未准入、路径不可写、网格重复/非有限/超过配额、全部运行失败。
- 独立验证：运行数等于笛卡尔积；每个成功结果等于直接调用；固定输入顺序和哈希可复现；失败与重试计数闭合。
- 关系：可批量调用 G005 生成参数族，也可批量调用 G003/G004 等数值工具；区别 G011/G012 在于不做采集或选择。

### G011 — 离线高斯过程贝叶斯优化

- 科学作用：对完全准入注册工具的 1–4 个连续参数，用固定 RBF 高斯过程和 Expected Improvement 做预算受控的离线序贯优化。
- 输入：目标模型码、基础参数、变量路径及上下界、数值输出路径、最小化/最大化、同次调用输出约束、初始样本数、总预算、固定种子、EI 探索量。
- 输出：最优可行参数/目标、全部评估历史、可行数、GP 状态、最后采集值和停止原因。
- 适用域：预算 5–40，固定噪声下限和归一化长度尺度；只支持连续变量与同一目标工具输出；不是在线生产控制。
- 失败：目标未准入、递归目标、输出非数值、边界警告未授权、无可行点、核矩阵数值失败。
- 独立验证：固定种子完全可复现；单调函数最优点靠近已知边界；目标方向反转结果对应；EI 非负。
- 关系：消费 G009 的局部敏感性认知但不要求导数；G006 是穷举基线；G012 处理多个目标。
- 依据：[Jones、Schonlau、Welch 的 Efficient Global Optimization](https://doi.org/10.1023/A:1008306431147)。

### G012 — NSGA-II 多目标优化

- 科学作用：对一个完全准入注册工具执行约束 NSGA-II，返回非支配 Pareto 解集与折中解。
- 输入：目标模型码、基础参数、1–5 个连续变量、2–4 个输出目标及方向、输出约束、种群规模、代数、固定种子、折中权重。
- 输出：评估次数、可行数、Pareto 集、目标范围、拥挤距离、归一化加权折中解、停止原因。
- 适用域：种群 8–48、代数 1–24、总评估不超过 1,200；固定 SBX/多项式变异参数；不是质量预测或现场推荐。
- 失败：目标未准入、路径/输出非法、全部个体不可行、预算超限、非有限目标。
- 独立验证：非支配性逐对验证；固定种子可复现；已知冲突目标保留两端；折中权重归一；可行性约束逐项满足。
- 关系：区别 F011 的单调单目标解析上界；与 G011 共享安全注册工具调用层但算法和输出不同。
- 依据：[Deb 等人的 NSGA-II](https://doi.org/10.1109/4235.996017)。

### G013 — 安全约束规则校验器

- 科学作用：对任意 JSON 输入/输出上下文执行显式、可审计的表达式树规则，报告违反项和修复建议。
- 输入：规则集 ID/版本、上下文对象、1–64 条规则；节点仅允许常量、路径、四则运算、聚合、比较和布尔组合；缺失路径策略。
- 输出：总体通过、错误/警告计数、逐规则取值与结论、违反项、规则集摘要哈希。
- 适用域：表达式深度不超过 12、节点数不超过 512；不执行字符串代码，不导入模块，不访问文件/网络/数据库。
- 失败：未知操作、除零、非数值算术、路径缺失、重复规则 ID、深度/节点超限。
- 独立验证：德摩根/比较恒等；质量与能量闭合样例；规则顺序不改变结论摘要；故障节点精确定位。
- 关系：依赖 A005 的守恒语义；可校验 G005/G006/G011/G012 或任意工艺工具结果，但不替代这些工具的内部物理边界。

### E022 — 铁氧化物逐级还原平衡

- 科学作用：计算 `Fe₂O₃→Fe₃O₄→FeO→Fe` 各级 CO/CO₂ 或 H₂/H₂O 还原反应的标准 Gibbs 能、Kp、平衡气比和实际 Q/K。
- 输入：反应级、还原气、温度 `[K]`、还原气与氧化气分压 `[bar]`。
- 输出：规范反应、ΔG° `[kJ/mol-reaction]`、Kp `[1]`、平衡与实际氧化气/还原气比、Q/K、反应方向、逐物种热力学分项和记录来源。
- 适用域：500–1100 K（由本波逐物种数据共同覆盖范围决定）；纯固相活度为 1、理想气体、1 bar 标准态；不处理非化学计量 FeO、固溶体或动力学。
- 数据：新增独立数据集 `DS_NIST_JANAF_IRON_REDUCTION_W18`，只追加 NIST WebBook/JANAF 的分段 Shomate 记录；不覆盖、不停用、不改写旧记录。运行时只读 `dataset_registry` 与 `thermodynamic_correlation`。
- 失败：数据库不可用、所需分段缺失/重叠、温区外、分压非正、ΔG/K 非有限。
- 独立验证：元素守恒；`K=exp(-ΔG°/RT)`；`Q=K` 时方向为平衡；逆气比与 K 互为对应；由数据库系数独立逐物种复算。
- 关系：依赖 A006、B005、B009；区别 E002 的总铁物料平衡；与 E011 的实际利用率共同给出平衡裕量。
- 数据依据：[NIST Fe](https://webbook.nist.gov/cgi/cbook.cgi?ID=C7439896&Table=on&Type=JANAFS)、[FeO](https://webbook.nist.gov/cgi/cbook.cgi?ID=C1345251&Plot=on&Type=JANAFS)、[Fe₂O₃](https://webbook.nist.gov/cgi/cbook.cgi?ID=C1317608&Mask=2)、[Fe₃O₄](https://webbook.nist.gov/cgi/formula?ID=C1309382&Table=on&Type=JANAFS)。

### H001 — 显式参数钢液脱氧平衡

- 科学作用：按 1 wt% Henrian 标准态，计算 Al/Si/Mn 与溶解氧生成纯 Al₂O₃/SiO₂/MnO 的平衡；用调用方显式 Wagner 一阶项修正活度。
- 输入：脱氧剂、温度 `[K]`、计算模式、K 或 ΔG°（二选一）、已知溶质浓度 `[wt%]`、氧化物活度、显式交互项、钢液质量 `[kg]`。
- 输出：K 与 ΔG°、两种活度系数、平衡氧或所需脱氧剂 `[wt%]`、活度与 Q/K、每 kg 氧对应脱氧剂/氧化物计量质量、原子量记录来源。
- 适用域：1773–1973 K、稀溶液（Al/Si/Mn 不高于 5 wt%，O 不高于 0.2 wt%）；纯或显式活度氧化物；不预测收得率、夹杂上浮和多氧化物固溶。
- 数据：K/ΔG°及交互参数由调用方显式给定，避免冒充数据库参数；Al/Si/Mn/O 原子量必须从现有 `DS_IUPAC_AW_2021` 的 `element_reference` 读取并返回记录级来源。
- 失败：K 与 ΔG°同时缺失或同时给定、交互项非法、未知元素、稀溶液超域、数据库不可用、求解结果非正或超域。
- 独立验证：`ΔG°=-RT lnK`；Wagner `log10(f_i)=Σe_i^j[%j]`；反应商回代等于 K；脱氧剂、氧和氧化物质量计量闭合；理想稀溶液极限 `f→1`。
- 关系：依赖 A003/A007/B009/B014–B017；区别 A007 的通用氧当量；为 H002/H003 所在钢包精炼工具族补充化学平衡。
- 依据：[Sigworth–Elliott 液态稀铁合金热力学](https://doi.org/10.1179/msc.1974.8.1.298)、[Costa e Silva 对 Wagner 参数适用域的复核](https://doi.org/10.2298/JMMB150901001C)。

## 3. 数据导入安全方案

1. 数据源先固化为带 URL、检索日期、分段温区、相态、系数和 SHA-256 的 JSON 资产。
2. 导入器默认 dry-run，验证字段、有限值、每一分段边界、重叠、系数数量、自然键和数据库现状。
3. apply 前用 `pg_dump --data-only` 备份 `dataset_registry` 与 `thermodynamic_correlation`；备份留在 `backups/`，不混入运行时资产。
4. apply 使用单事务，只插入新 dataset ID 与新相关记录；不执行 UPDATE/DELETE/TRUNCATE，不修改旧 DS002 数据。
5. 再次 dry-run 必须得到 `inserted=0、unchanged=全部、conflict=0`；逐行校验数据库值与 JSON checksum。
6. 导入失败整体回滚；E022 保持未注册或不具资格，绝不以硬编码常数兜底。
