## 4. 大模型调用契约

获取最终合格工具清单：

```http
GET /api/v1/tools
```

响应包含30个 OpenAI-style function定义，每个定义具有唯一 `function.name`、JSON Schema参数、`tool_uid`、`catalog_id`、`model_code`、版本、数据要求和资格状态。

调用格式：

```http
POST /api/v1/tools/metallurgy_b002/call
Content-Type: application/json

{
  "arguments": {
    "species": "O2(g)",
    "temperature": 900
  },
  "options": {
    "validate_boundary": true,
    "return_provenance": true
  }
}
```

规则：只暴露 `fully_eligible=true` 的工具；拒绝未知字段；数值输入按Schema单位解释；数据库缺失或不可用时返回 `MISSING_DATA`/`DATA_BACKEND_UNAVAILABLE`，不回退到Python静态常量；成功结果的 `actual_data_records` 包含数据集、表、记录ID、版本和来源。

## 7. 未解决问题与适用边界

1. D001/D002是透明、零维、静态工程估算工具，不是在线炉况控制模型；BOF参数集明确标记为尚未取得工厂控制用途冶金复核。该限制不影响其作为固定版本静态估算工具的可执行资格，但阻止其用于生产控制决策。
2. B006–B009使用温度无关ΔH/ΔS近似，尚未加入反应ΔCp温度修正；其适用域已在模型卡中声明。
3. B011只有Fe/FeO和Al/Al2O3两条Ellingham线，超温区会给出边界警告；不会外推成“数据库事实”。
4. 运行时30项只直接覆盖表格主目录26项；4项为有科学差异的扩展/粒度变体。目录覆盖和运行时数量继续分开统计，禁止用别名填补差额。
5. FastAPI当前依赖组合对 `TestClient` 给出Starlette弃用警告；不影响ASGI调用结果，后续升级依赖时应单独验证，不在本轮扩大变更范围。
