# P1-W17：109→113 ODE、查表、敏感性与不确定度实施蓝图

## 1. 范围、基线与停止条件

本波只实施主目录中的 `G004`、`G008`、`G009`、`G010` 四项，把真实可执行工具数从 109 增至 113，把主目录覆盖数从 91 增至 95。既有 109 项不改科学实现、不改运行时 ID、不撤销资格；不连接传感器、PLC、企业生产库，不调用外部大模型 API，不生成正式研究数据集。

四项均为调用方显式输入驱动的确定性数值工具。`G004` 使用项目已固定的 SciPy 1.18.1；`G008` 使用透明的一维线性/最近邻与二维双线性/最近邻算法；`G009`、`G010` 只能调用统一注册中心中的既有合格工具，不接受 Python、JavaScript、公式字符串、lambda、模块路径或 `eval` 表达式。现有 `Tools/requirements.txt` 已固定 `scipy==1.18.1`，本波不安装新依赖、不修改数据库。

若发现必须增加现场标定、外部训练数据、数据库迁移、未固定依赖或任意代码执行，立即停止对应工具计数并先报告。其他停止条件：与现有工具实质重复、无法给出可审计闭合量、正常用例少于 3 个、边界/失败用例少于 2 个、独立性质不成立、HTTP/forced route 失败，或新增工具专项回归失败。

## 2. 安全架构与调用链

```text
结构化反应网络 ──> G004 ODE积分 ──┐
                                   ├─> G009 局部敏感性 ──> 参数排序
显式版本化规则表 ──> G008 插值 ────┤
                                   └─> G010 Monte Carlo ──> 输出分布/失效概率
任一既有合格工具 ───────────────────┘
```

`G009`、`G010` 的目标只由 `target_model_code` 指定，目标输入通过 `base_arguments` 提交并继续接受目标工具自己的 Schema、单位、适用域和错误检查。参数与输出使用受限的点路径访问；禁止递归调用自身或相互嵌套形成分析循环。单次参数数和样本数设硬上限，目标工具任何失败默认使分析失败，避免丢弃失败样本后产生选择偏差。

## 3. 工具契约

### 3.1 G004 结构化质量作用反应 ODE

- 输入：唯一物种名数组、对应初始浓度 `mol/m3`、0～100 个结构化反应、起止时间 `s`、输出点数、求解器方法、相对/绝对容差和最大步长；可选单物种浓度阈值事件。
- 反应对象：名称、反应物/产物化学计量数组、正/逆速率常数 `1/s`、参考浓度 `mol/m3`。统一速率定义为 `r=c_ref[k_f∏(c_i/c_ref)^ν_i-k_r∏(c_i/c_ref)^ν_i]`，使任意反应级数下输入速率常数单位保持明确。
- 算法：构造安全的质量作用右端项，调用 `scipy.integrate.solve_ivp`；支持 `RK45`、`DOP853`、`Radau`、`BDF`、`LSODA`，输出固定采样点、末态速率、收敛状态和事件位置。
- 输出：时间序列、末态浓度、末态逐反应净速率、求解器统计、最小浓度、事件状态和时间。
- 适用域：封闭、均匀、等温且速率常数已由调用方确定的批式网络；不做传热传质、活度修正或参数拟合。
- 失败：物种/反应重名、未知物种、化学计量或速率非法、时间/容差非法、显著负浓度、积分失败或事件字段不完整。
- 独立验证：一阶不可逆 `A→B` 解析指数解；可逆 `A⇌B` 解析平衡；无反应不变性；守恒网络 `A+B` 总浓度闭合；刚性例用 BDF 收敛。
- 关系：消费 C001/C004 等动力学参数；与 G002 数值稳定性互补；可作为 G009/G010 的目标工具。

### 3.2 G008 一/二维规则网格插值与查表

- 输入：显式 `table_id`、`table_version`、维数、轴及单位、扁平值数组及输出单位、查询点、`linear`/`nearest` 方法、`reject`/`clamp` 越界策略。
- 算法：严格递增轴上的一维分段线性或最近邻、二维双线性或最近邻；最近邻中点固定选择低索引，结果可复现。
- 输出：插值值、有效查询点、夹持轴、是否精确网格点、角点坐标/值/权重、域外距离、表 ID 与版本。
- 适用域：1～2 维直角规则网格；不处理散点、样条、高维表或企业实时表。
- 失败：轴非严格递增、非有限值、值数组形状不符、缺少二维字段、`reject` 模式域外查询、单位或版本为空。
- 独立验证：线性插值精确再现仿射函数；二维角点权重和为 1；网格点结果精确；最近邻中点规则；夹持与拒绝边界独立验证。
- 关系：可消费 A004 单位换算后的表格；为 G009/G010 提供确定性、可解析交叉验证的目标函数。

### 3.3 G009 已注册工具局部敏感性

- 输入：`target_model_code`、目标工具的 `base_arguments`、标量 `output_path`、1～12 个参数路径/标签/单位/绝对扰动步长，以及是否接受目标边界警告。
- 算法：基线一次，逐参数在 `x-h` 与 `x+h` 各调用一次目标工具；计算二阶中心一阶导数、中心二阶导数、弹性和步长尺度效应，并排序。
- 输出：目标工具身份/版本、基线输出、调用次数、逐参数正负响应、导数、曲率、弹性、排序与边界告警。
- 适用域：目标必须是已注册且声明合格的确定性工具，参数和输出必须是有限标量；扰动点必须仍在目标适用域。
- 失败：未知/不合格/递归目标、路径不存在、叶值非数值、步长非正、目标调用失败、输出非标量或非有限。
- 独立验证：线性函数导数精确；二次函数中心一阶/二阶导数精确；无量纲弹性解析值；目标调用次数 `1+2p`；步长过大产生边界警告。
- 关系：上游可为 G004/G008 或任一既有合格工具；与 A010 不确定度传播不同，G009 给局部导数和曲率；结果可指导 G010 分布范围。

### 3.4 G010 已注册工具 Monte Carlo 不确定度传播

- 输入：`target_model_code`、`base_arguments`、标量 `output_path`、1～8 个带单位的不确定参数；支持 `uniform`、`normal`、`triangular`；显式相关矩阵、固定整数种子、10～2000 个样本、失效阈值和方向、是否接受目标边界警告。
- 算法：Cholesky 分解相关矩阵；固定种子生成相关标准正态，借助正态 CDF 映射到指定边缘分布；逐样本调用目标工具；用样本统计、线性分位数和 Wilson 区间汇总。
- 输出：样本数/调用数、参数样本摘要和实际相关矩阵、输出均值/样本标准差/标准误、最小/最大、P05/P50/P95、失效概率及 95% Wilson 区间、种子与目标版本。
- 适用域：离线、小规模不确定度传播；不用于在线控制、稀有事件高精度估计或替代正式概率安全评估。
- 失败：分布字段不完整、相关矩阵非对称/非正定、递归目标、目标调用失败、输出非标量、样本超限或结果非有限。
- 独立验证：相同种子逐字段复现；均匀样本严格位于边界内；常量目标标准差为零；仿射目标样本均值/方差与解析值在 Monte Carlo 误差内；Wilson 区间包含点估计。
- 关系：可消费 G009 的敏感参数排序；可调用 G004/G008 及其他合格工具；区别 G009 的局部差分，G010 给全分布传播。

1. 注册到统一 `ModelRegistry`，提供唯一、稳定的 `metallurgy_*` function name 和 Draft 2020-12 Schema。
