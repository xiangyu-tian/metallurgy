F005运行时读取：

- `metallurgy_v2.casting_material_property_correlation`
- `metallurgy_v2.casting_boundary_profile`

批准物性集：

2. `NIST_SRM1155A_316L_2019_V1`：仅用于公开资料参考验证，`REFERENCE_VALIDATION_ONLY`。

NIST来源为Pichler等人的316L热物性论文，DOI `10.1007/s10853-019-04261-6`。其中导热系数是由公开电阻率与Wiedemann–Franz关系得到的透明估计，不冒充直接测量值。两套物性均不允许以 `engineering` 用途执行。

Repository新增一次加载批准物性模型、相关式求值和焓导数计算。数据库不可用、记录缺失、温度越域或属性缺失均显式返回标准错误，不存在JSON常数回退。

## 4. 数值实现

每个时间步求解：

1. 在当前Picard迭代温度上读取密度、焓、焓导数和导热系数；
2. 采用 `H(T_new) ≈ H(T*) + dH/dT|(T*) (T_new-T*)` 线性化焓项；
3. 对内部面导热系数使用调和平均；
4. 定表温边界使用半单元距离，定热流采用外向为正的Neumann符号；
5. 用 `scipy.linalg.solve_banded` 求解三对角系统；
6. Picard残差满足温度容差后接受时间步；超迭代次数或非有限结果返回 `NUMERICAL_ERROR`；
7. 逐步核算储能变化与表面移热，闭合残差超过2%时拒绝结果。

固相率由批准数据库相关式计算。坯壳厚度定义为从表面到首次跨越调用者给定固相率阈值的位置，并在线性区间内插值；结果始终限制于 `[0, half_thickness]`。

## 5. 独立科学验证

### 5.1 定表温半无限体解析解

数学介质参数给出 `alpha=1e-4 m²/s`，初温800 K，表面300 K，1 s时解析解为：

`T(x,t)=300+500 erf[x/(2 sqrt(alpha t))]`

| 网格/时间步 | 全剖面RMSE |
| --- | ---: |
| 20 / 0.02 s | 1.97898 K |
| 80 / 0.02 s | 0.57117 K |
| 80 / 0.01 s | 0.33063 K |

最终加密解最大节点误差为0.94382 K。空间和时间加密均降低解析误差。

### 5.2 定热流半无限体解析解

外向热流100000 W/m²、导热系数100 W/(m·K)、1 s时解析表面温度为788.716208 K；数值结果为788.719238 K，误差0.003030 K，全剖面RMSE为0.004800 K。累计移热严格为100000 J/m²。

### 5.3 NIST参考物性下的坯壳收敛

初温1750 K、表面1500 K、计算5 s：

| 网格/时间步 | 最终坯壳厚度 |
| --- | ---: |
| 40 / 0.05 s | 0.00455862 m |
| 80 / 0.05 s | 0.00459735 m |
| 80 / 0.025 s | 0.00461514 m |

40→80网格相对差约0.84%，0.05→0.025 s时间步相对差约0.39%。坯壳历史单调不减，全部固相率位于 `[0,1]`，能量闭合相对残差约 `4e-11`。

### 5.4 守恒、边界与失败

- 零热流保持800 K均匀初温，累计移热为0，储能闭合残差小于 `1e-6 J/m²`。
- 不存在的物性集返回 `MISSING_DATA`。
- NIST验证物性用于工程计算返回 `MODEL_NOT_APPLICABLE`。
- F007来源缺执行ID返回 `MISSING_DATA`。
- 数据库边界与物性集不匹配返回 `MODEL_NOT_APPLICABLE`。
- 温度越出批准相关式范围返回 `OUT_OF_DOMAIN`。
- 时间步大于总时长返回 `INVALID_INPUT`。

## 10. 已知限制与停止条件

- NIST 316L物性仅是参考验证资产，导热系数还是派生估计；当前没有工程批准的实际钢种物性集，因此F005不得用于生产控制。
- 首版是一维平板半厚度模型，只支持中心对称和常值表面边界；未建模二维角部、铸坯鼓肚、流动过热、喷淋时变换热或设备在线反馈。
- 网格/时间加密结论只覆盖已批准基准域；工程钢种引入后必须重新执行独立验证。
- F006尚未实现。F005提交推送后本波停止，等待用户确认是否进入W5C的F006凝固终点事件定位。
