## 3. 工具科学契约

### 3.1 A009 异常值检测

- 科学目标：对调用方提交的一维数值样本标记“待调查异常”，不删除、修正或预测数据。
- 输入：`values [caller_unit]`、`method=iqr/modified_z`、阈值、可选逐点标签。
- 输出：逐点分数与标签、异常索引/标签、中心、稳健尺度、上下阈值、异常数量、方法版本。
- 适用域：3–10000 个有限标量；同一组数据必须同单位；不做多变量异常检测、时序漂移、Isolation Forest 或自动清洗。
- 失败/边界：非有限值、标签数不一致、阈值非法、非恒定样本但 IQR/MAD 为零时失败；完全恒定样本返回边界警告和零异常。
- 区别与关系：与 A004 都是输入预处理，但 A004处理成分归一化，A009输出可疑观测标签；未来 G015 是绑定训练分布的 OOD 检测，不与本工具同义。
- 独立验证：手算四分位数/MAD；平移与正比例缩放不改变异常标记；输入顺序置换只置换逐点输出。

### 3.2 A010 不确定度传播

- 科学目标：对显式标量测量模型执行一阶 GUM 或固定种子 Monte Carlo 传播。
- 输入：受限数学表达式、变量数组（名称、均值、标准不确定度、分布）、可选协方差矩阵、方法、样本数、种子、覆盖因子。
- 输出：输出估计、合成标准不确定度、覆盖区间、数值灵敏度系数、方差贡献、相关矩阵诊断、样本数/种子、方法版本。
- 表达式域：仅允许变量、有限数值、`+ - * / **`、一元正负和 `exp/log/sqrt/sin/cos/tan/abs`；禁止属性访问、下标、导入和任意调用。
- 适用域：1–12 个变量；一阶法适用于局部线性化，Monte Carlo 为最多 200000 个样本的离线传播；首版相关变量只支持联合正态。
- 失败/边界：表达式非法、变量名重复、协方差非对称/非半正定、表达式越定义域或结果非有限；全部零不确定度返回边界警告。
- 区别与关系：A010只传播一个显式标量表达式；未来 G010 将编排任意已注册工具并传播其输出分布，两者粒度不同。
- 独立验证：线性模型解析方差；协方差交叉项；平移模型输出但不改变不确定度；固定种子重复性；Monte Carlo 与解析结果在统计容差内一致。

### 3.3 B020 二元相界插值

- 科学目标：在调用方提供的离散二元相界点之间进行不外推的分段线性或保形 PCHIP 插值。
- 输入：边界类型、独立量类型、点数组 `x/y/u_y`、查询值、方法。
- 输出：插值值、一阶导数、所在区间、是否命中原点、输入不确定度传播、PCHIP/线性方法差、算法版本。
- 适用域：2–500 个严格递增 x；查询必须位于闭区间；相界来源和单位由调用方显式声明。
- 失败/边界：重复/乱序 x、非有限值、不确定度不完整或为负、查询越界；端点查询返回边界提示但不外推。
- 区别与关系：B019在已知两端相组成时做杠杆相分数；B020插值相界位置；B027从理想 VLE 方程求边界事件。
- 独立验证：节点精确重现；线性数据被两种方法精确重现；单调数据无超调；线性不确定度由权重平方和复核。

### 3.4 B022 多元多相 Gibbs 最小化

- 科学目标：对调用方显式给出的物种计量、标准 Gibbs 能和理想混合相，在元素守恒下求非负平衡物种量。
- 输入：温度、元素总量、物种数组（名称、相、元素计量、`g0[J/mol]`、相模型 `pure/ideal`）、容差和迭代上限。
- 输出：平衡物种量、相量、相组成、总 Gibbs 能、元素残差、最大残差、活跃物种、求解器/迭代/收敛信息。
- 适用域：1–8 元素、2–40 物种；纯相与理想混合相；所有 `g0` 必须使用同一参考态、温度和压力。
- 失败：元素矩阵不可行、物种计量非法、相模型混用、秩或约束不闭合、数值不收敛、元素残差超限。
- 区别与关系：B013只处理数据库支持的理想气体反应平衡；B022消费显式 Gibbs 模型并支持多相；B023消费批准 TDB 并支持真实 CALPHAD 模型。
- 独立验证：元素守恒；纯相问题与线性规划参考一致；理想混合化学势/KKT 条件；任意可行微扰不能降低报告解的 Gibbs 能。

### 3.5 B023 CALPHAD 平衡计算

- 科学目标：在单一 T/P/铁基成分点上调用批准 TDB，返回稳定相、相量、相组成、化学势和体系 Gibbs 能。
- 输入：钢成分 `[wt%]`、温度 `[K]`、压力 `[Pa]`、可选批准相子集、模型资产 ID。
- 输出：稳定相、相分数、各相组分摩尔分数、组元化学势 `[J/mol]`、体系摩尔 Gibbs 能 `[J/mol]`、相分数闭合残差、数据/求解器版本和资产哈希。
- 适用域：数据库批准的 Fe 基成分、673–2000 K、固定批准相集；首版不接受任意 TDB、不扫温区、不绘相图、不处理重复相顶点/互溶间隙。
- 失败：数据库不可用、资产未批准/哈希不符、成分超域、相不在批准集、求解失败、相分数或组成不闭合。
- 区别与关系：F001/F002只输出液/固相线端点，F004输出凝固分数曲线；B023输出单状态完整 CALPHAD 平衡。B022是显式理想模型的替代路径。
- 独立验证：相分数和每相组成闭合；稳定相均有正相量；GM/MU 有限；纯 Fe 熔点两侧相稳定性与数据库基准一致。

### 3.6 B024 Scheil–Gulliver 微偏析

- 科学目标：输出残余液相及瞬时固相的逐组元微偏析路径，而不重复 F004 的凝固分数曲线用途。
- 输入：钢成分 `[wt%]`、起始温度 `[K]`、降温步长 `[K]`、残余液相停止阈值、可选批准相子集、模型资产 ID。
- 输出：温度路径、液/固分数、液相组成、瞬时与累计固相量、各相瞬时组成、终态累计相量、各溶质最大液相富集倍数、逐组元总量闭合残差、收敛和版本信息。
- 适用域：批准 Fe 基 TDB；液相完全混合、固相无回扩散、界面局部平衡；不代表有限扩散、宏观偏析或现场连铸预测。
- 失败：数据资产问题、初始状态无液相、成分/温区/相集超域、不收敛、相量或组元闭合超限。
- 区别与关系：F004面向 `fs(T)` 和液/固相线；B024面向相/组元微偏析并提供逐组元守恒诊断，不能作为 F004 的别名或输出包装。
- 独立验证：每点 `fl+fs=1`；液相与累计固相量闭合；逐组元初始量等于残液加各步凝固量；富集倍数由路径重新计算。

### 3.7 B025 相图一致性校验

- 科学目标：校验调用方或 B022/B023 输出的相区、邻接、杠杆规则和最低 Gibbs 能声明，不自行预测相图。
- 输入：组元数、外加约束数、相区数组、邻接数组、可选杠杆规则测试、可选 Gibbs 稳定性测试和容差。
- 输出：通过状态、规则检查总数、违规项（规则/位置/严重度/证据）、最大杠杆残差、最大 Gibbs 稳定性差、算法版本。
- 适用域：平衡相图的离散拓扑/测试点；不验证动力学相图、未经说明的亚稳态或实验误差模型。
- 失败：ID 重复、引用不存在的相区、组成维度不符、相分数不闭合、没有任何可执行检查；物理违规以成功结果中的违规列表返回。
- 区别与关系：B018计算单点相律自由度，B019计算单条杠杆相分数，B025综合审查多相区和多类证据；可校验 B022/B023 输出。
- 独立验证：构造合法二元相图零违规；负自由度、非法邻接、杠杆残差和错误最低 Gibbs 声明均被独立捕获。
