## 4. 大模型调用接口

七项均通过以下本地可执行链：

1. `GET /api/v1/tools` 返回唯一function定义；
2. `POST /api/v1/tools/{tool_name}/call` 能按模型参数执行并返回标准结果；
3. `POST /api/v1/experiments/run` 的 `forced` 模式逐项强制调用成功；
4. 同一接口的 `autonomous` 模式能按关键词召回对应工具。

`Tools/benchmarks/llm_tool_call_cases_p1_w9.json` 为七项各自准备了隔离的provider-forced冒烟用例，每项含4个结果断言。它不是正式研究数据集。

本轮未运行真实外部大模型：当前进程中的 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL` 均未设置。本地forced路由验证不能冒充外部provider函数调用。
