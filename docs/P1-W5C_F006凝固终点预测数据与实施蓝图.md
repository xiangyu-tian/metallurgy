# P1-W5C：F006凝固终点预测数据与实施蓝图

日期：2026-09-01

基线：`34abbf9 feat(tools): 新增F005一维坯壳工具至44项`

## 1. 主表定位与首版取舍

主表 `02_小模型清单120` 的F006定义为：

- 名称：凝固终点预测；
- 方法：温度场固相率阈值或回归代理；
- 输入：拉速、过热度、水量、钢种、断面；
- 输出：凝固终点位置、置信区间；
- 数据：DS042浇次/温度/拉速/水量/质量数据与物性；
- 风险：必须绑定钢种、断面、设备、喷嘴与传感器配置，高风险报警需人工或联锁复核。

首版只实施主表允许的“固相率阈值”物理数值路径，不训练回归代理。原因是DS042属于受限内部数据，当前没有可证明授权、脱敏、训练/验证划分、漂移和OOD治理的真实浇次集。首版不能用公开数据或项目生成数据冒充DS042。

F006不是F005改名包装器：F005求解局部温度场、固相率和坯壳生长；F006独立完成中心固相率曲线校验、首次阈值事件定位、区间插值、数值分辨率、设备内外判断和配置适配性检查。

## 2. 首版调用路径

首版只认证显式上游曲线路径：

```text
F005执行结果
  └─ time_history[].time_s / center_solid_fraction
       + F005 execution_id
       + casting_speed_m_s
       + approved machine_configuration_id
       ↓
F006首次阈值交点与设备边界判断
```

F005的 `time_history` 增加 `center_solid_fraction`，不删除或重命名既有字段。F006首版不在模型内部隐藏调用F005，避免丢失上游执行号、配置和数据来源。端到端HTTP验证必须先实际执行F005，再把曲线及其执行ID传入F006。

## 3. W5C-Data：追加式数据层

### 3.1 新增表

`metallurgy_v2.casting_machine_configuration`：

- 不可变自然键 `machine_configuration_id`；
- `dataset_id`、设备/配置名称和版本；
- 断面宽度/厚度、结晶器长度、有效冶金长度；
- 批准拉速范围；
- 单位制、用途域、来源类型、来源、许可、不确定度、元数据和批准状态；
- 约束：尺寸、长度和拉速均为有限正值；结晶器长度不得超过有效冶金长度；最大拉速大于最小拉速。

`metallurgy_v2.casting_endpoint_benchmark_case`：

- 基准ID、F006模型编号、设备配置ID；
- 中心固相率曲线、阈值、拉速、预期交点和容差；
- 参考类型、来源、适用域和元数据。

首版不创建或查询企业浇次表，不导入DS042。将来只有获得授权后，才另行设计 `casting_run_condition` 和代理模型资产表。

### 3.2 版本化验证资产

新增项目生成的数学验证数据集 `DS_F006_ENDPOINT_BENCH_V1`：

- 两个虚拟设备配置：长设备用于“设备内终点”，短设备用于“设备外终点”；
- 三个可手算的单调固相率曲线基准；
- 用途域固定为 `MATHEMATICAL_BENCHMARK_ONLY`；
- 设备名称、长度和断面不得声称对应任何真实工厂；
- `engineering`调用必须返回 `MODEL_NOT_APPLICABLE`。

JSON只作为审查和导入资产。F006运行时必须通过PostgreSQL Repository读取设备配置，不允许从JSON或Python常数回退。

### 3.3 数据库安全流程

1. 用用户提供的PostgreSQL 17 `pg_dump`创建自定义格式预变更备份；
2. 记录文件大小与SHA-256；
3. 恢复到临时数据库，逐表核对非系统表行数；
4. 先执行回滚dry-run；
5. 只允许 `CREATE TABLE/INDEX IF NOT EXISTS` 与冲突校验后的insert；
6. apply必须携带已验证备份路径；
7. 导入后对非目标表做行数差异核对；
8. 重复dry-run必须显示全部unchanged；
9. 删除临时验证数据库前确认精确数据库名，不触碰原数据库。

## 4. F006统一Schema

函数名：`metallurgy_predict_solidification_end`

### 4.1 输入

| 字段 | 类型/单位 | 约束 |
| --- | --- | --- |
| `machine_configuration_id` | string | PostgreSQL中批准的配置 |
| `calculation_purpose` | validation/engineering | 数学配置只允许validation |
| `upstream_execution_id` | string | F005执行ID，不能为空 |
| `casting_speed_m_s` | number，m/s | 必须落在设备批准范围 |
| `endpoint_solid_fraction_threshold` | number，1 | `(0,1]` |
| `center_solid_fraction_curve` | array | 2至2001点；每点含time_s和center_solid_fraction |

曲线时间必须严格递增、从非负时间开始；固相率必须位于 `[0,1]` 且单调不减。不接受调用者同时传轴向位置，统一由 `z=v*t` 计算，避免时间—距离口径冲突。

### 4.2 事件定位

寻找首个满足：

```text
fs_center(t) >= endpoint_solid_fraction_threshold
```

若阈值位于相邻两点之间，使用线性插值：

```text
t* = t0 + (threshold-fs0)/(fs1-fs0) * (t1-t0)
z* = casting_speed * t*
```

数值分辨率以包围交点的时间宽度和距离宽度报告；首版不把它称为统计置信区间。主表中的“置信区间”只有在未来代理模型完成统计校准后才能提供。

### 4.3 输出

- `solidification_end_time_s`、`solidification_end_position_m`；
- 阈值和左右插值点；
- `time_resolution_s`、`position_resolution_m`；
- `position_interval_m`；
- `equipment_status`：`inside_machine`、`at_machine_exit`、`beyond_machine_exit`；
- 有效冶金长度、出口中心固相率、曲线点数；
- F005上游执行ID、设备配置ID/版本、算法版本。

### 4.4 失败与边界

- 缺F005执行ID或曲线字段：`INVALID_INPUT`/`MISSING_DATA`；
- 时间不严格递增、固相率不单调或超 `[0,1]`：`INVALID_INPUT`；
- 曲线未跨越阈值：`MODEL_NOT_APPLICABLE`；
- 设备配置不存在：`MISSING_DATA`；
- 拉速越出批准范围：`OUT_OF_DOMAIN`；
- 数学配置用于工程用途：`MODEL_NOT_APPLICABLE`；
- 首点或某点恰好等于阈值：成功并返回带边界警告的零宽或单侧插值区间；
- 终点超过有效冶金长度：成功返回 `beyond_machine_exit` 和风险警告，不伪造设备内终点。

## 5. 关系与计数

- `dependencies=[F005]`：F006必须接受F005上游执行ID和中心固相率曲线；
- 与F005为 `consumes_output_from`；
- 与F004为 `overlaps_with`：两者都处理固相率，但F004给温度—固相率关系，F006定位中心液芯消失位置；
- 与未来回归代理形成相同输出、不同理论路径的真实重叠，但代理未实现前不得登记为运行时工具。

完成后目标计数：运行时45、目录覆盖41、数据必需型21；只有全部资格通过时F006才设置 `count_eligible=true`。

## 6. 资格与独立验证

至少覆盖：

1. 三个正常用例：线性交点、非均匀曲线交点、设备外终点；
2. 边界：曲线点恰好等于阈值；
3. 失败：未跨阈值、非单调曲线、拉速越域、缺执行ID；
4. 手算线性插值交点；
5. `z=v*t` 单位恒等；
6. 提高终点固相率阈值不得使预测终点提前；
7. 曲线加密后交点保持一致；
8. F005→F006实际HTTP链保留两个执行ID和两层数据来源；
9. F006单工具隔离的供应商命名强制调用。

## 7. 停止条件

以下任一情况出现即不得认证F006：

- 数据库备份或恢复核对失败；
- 迁移含更新、删除、截断或破坏性DDL；
- 设备配置没有用途域、版本、单位或来源；
- F006只返回F005最后一行，没有独立交点和设备边界算法；
- 无法证明阈值单调性、加密一致性或 `z=v*t`；
- 大模型调用需要补隐藏机长、拉速或默认钢种；
- 将项目生成配置表述为真实生产设备，或绕过DS042授权要求。
