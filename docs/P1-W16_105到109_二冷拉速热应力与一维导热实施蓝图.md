# P1-W16：105→109 二冷分区、拉速、热应力与一维导热实施蓝图

## 1. 范围、基线与停止条件

本波只实施主目录中的 `F009`、`F011`、`F014`、`G003` 四项，把真实可执行工具数从 105 增至 109，把主目录覆盖数从 87 增至 91。既有 105 项不改科学公式、不改运行时 ID、不撤销资格；不连接传感器、PLC、企业生产库，不调用外部大模型 API，不生成正式研究数据集。

四项均采用调用方显式输入的确定性公式或数值算法，使用 Python 标准库与现有 NumPy，不新增依赖、不修改数据库。若实现过程中发现必须引入现场标定、外部数据集、数据库迁移或新依赖，立即停止对应工具资格计数并先报告。

其他停止条件：与既有工具实质重复、算法无法给出可审计闭合量、正常用例少于 3 个、边界/失败用例少于 2 个、独立数学性质不成立、真实 HTTP/forced route 失败，或全量回归失败。

## 3. 工具契约

### 3.1 F009 二冷分区水量分配

- 输入：总水量 `m3/h`；2～50 个分区的唯一名称、正分配权重、目标移热 `kW`、最小/最大水量 `m3/h`；水密度、比热、进出口温度。
- 算法：求唯一比例系数 `λ`，使 `V_i=clip(λw_i,Vmin_i,Vmax_i)` 且 `ΣV_i=V_total`。用 `Q_i=V_i ρ cp ΔT/3600` 计算热容量。
- 输出：逐区水量、热容量、需求覆盖率/余量、上下限激活状态；总水量闭合残差、总热容量和总需求。
- 失败：总水量不在 `ΣVmin～ΣVmax`、分区名重复、权重非正、上下限颠倒、温升非正或投影不收敛。
- 验证：无激活边界时严格按权重比例；每区满足上下限；分区和等于总量；热容量由独立水侧显热式复算。
- 关系：消费 F008 的总水量；可消费 F005/F007 的移热需求；输出可供 F011 使用。与 F008 是“总量→分区”的原子/综合关系。

### 3.2 F011 最大可行拉速

- 输入：流股数、断面、钢密度、有效设备长度、允许拉速下/上限、最低停留时间、最低坯壳厚度、平方根坯壳增长系数、可用二冷热功率、所需单位钢移热。
- 约束：`v≤L/t_req`；`v≤L(K/s_min)^2`；`v≤Q_available/(n A ρ q_req)`；并满足设备速度区间。
- 输出：推荐最大可行拉速、四类上限与限制约束、停留时间、预测坯壳厚度、钢流量、所需热功率、各约束余量和产量。
- 失败：物理参数非正、速度区间颠倒、综合可行上限低于最低拉速，或闭合量非有限。
- 验证：推荐值等于所有上限最小值；在推荐值处所有余量非负；断面或比移热增加使冷却上限不增；设备长度同比缩放使时间/坯壳上限同比缩放。
- 关系：F006 可给最低停留时间，F008/F009 可给可用热功率；与 G012 的区别是仅解单调约束下“最大拉速”这一解析目标。

### 3.3 F014 分层热应力/应变

- 输入：约束模式、参考温度；1～100 层的名称、温度、权重、弹性模量、线膨胀系数和屈服强度。
- 完全约束：公共总应变为零；`σ_i=clip[E_i(−α_iΔT_i),−σy_i,σy_i]`。
- 自平衡膜：忽略曲率，用二分法求公共总应变 `ε0`，使 `Σw_i clip[E_i(ε0−α_iΔT_i),±σy_i]=0`。
- 输出：逐层热/弹/塑性应变、试应力、实际应力和屈服利用率；最大拉/压应力、危险层、公共应变、加权平均应力及平衡残差。
- 失败：层名重复、绝对温度/模量/屈服非正、权重或热膨胀系数非法、求根不收敛。
- 验证：均匀温度自平衡模式应力为零；单层完全约束与解析式一致；应力不超过屈服强度；自平衡模式加权应力和近零。
- 关系：可消费 G003/F005 温度场；区别于温度求解器，本工具只做显式温度场的简化力学后处理。

### 3.4 G003 一维瞬态导热 PDE

- 输入：长度、节点数、时长、时间步、密度、比热、导热率、均匀或逐节点初温、均匀体热源、左右边界对象、快照数。
- 边界：`dirichlet` 给边界温度；`heat_flux` 给正向入域热流；`convection` 给环境温度与换热系数。字段必须按模式完整且互斥。
- 离散：单元中心有限体积/显式 Euler。根据内部单元和两端边界的离散对角系数计算最大稳定时间步，任何实际步的最大系数必须 `≤1`。
- 输出：节点位置与最终温度、有限快照、边界末态热流、Fourier 数、稳定系数和最大稳定步长；储能变化、累计边界入热、体热源输入和能量闭合残差。
- 失败：时间步不稳定、步数超过 200000、边界字段冲突、初温长度不符、绝对温度降至非正或能量闭合超限。
- 验证：绝热零源均匀场严格保持；单步结果与控制体手算一致；累计储能等于边界加体热源；对称边界保持对称；不稳定时间步失败。
- 关系：消费 G001 网格建议并由 G002 审核显式稳定性；T001 是稳态解析重叠，T003 是小 Bi 零维退化，F005 是温变物性与相变的专用隐式焓法。
