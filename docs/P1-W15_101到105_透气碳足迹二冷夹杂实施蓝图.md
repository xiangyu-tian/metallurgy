# P1-W15：101→105 透气性、碳足迹、二冷与夹杂工具实施蓝图

## 1. 范围与停止条件

本波只实现 `E015`、`E020`、`F008`、`F018` 四项，把注册且完全合格的真实工具数从 101 增至 105，把表格主目录覆盖数从 83 增至 87。既有 101 项不改科学公式、不改运行时 ID、不撤销资格；不接现场传感器、PLC 或企业生产数据库，不调用外部大模型 API，不生成正式研究数据集。

遇到下列任一情况立即停止资格计数：公开来源无法支持固定因子版本、数据库备份校验失败、dry-run 发现自然键冲突、运行时需要静态回退、正常样例少于 3 个、边界/失败样例少于 2 个、独立数学性质不成立，或全量回归失败。

## 2. 工具契约

## 3. 数据设计与安全导入

只有 E020 依赖数据库。新增版本化资产 `bf_emission_factors_w15_v1.json`、迁移 `012_bf_emission_factors.sql`、导入器 `import_bf_emission_factors.py` 和只读 Repository：

- 新增 `metallurgy_v2.emission_factor`，自然键为 `(dataset_id, factor_set_id, factor_code, source_version)`；不 ALTER、不 UPDATE、不 DELETE 既有业务表。
- 数据集 `DS_BF_GHG_FACTORS_W15` 只含公开固定因子。燃料燃烧因子采用 IPCC 2006 Guidelines Volume 2 Chapter 2 Table 2.3，单位 `kg/TJ_NCV`；电力因子采用中国生态环境部 2024 年全国电力碳足迹因子，单位 `kgCO2e/kWh`。
- 燃烧 CH4 和 N2O 的 GWP100 分别采用 IPCC AR6 的 27.0 和 273；数值与适用说明存入每条数据库记录，运行时不硬编码。
- 导入顺序固定为：资产结构与校验和验证 → 数据库 dry-run/回滚 → `pg_dump -Fc` 全库备份与 SHA-256 校验 → 携带备份路径 `--apply` → 数量/内容/导入日志只读复核。
- 导入器持有事务级 advisory lock，遇到相同自然键但科学内容不同立即回滚；运行时数据库不可用或因子缺失返回 `DATA_BACKEND_UNAVAILABLE`/`MISSING_DATA`，禁止 Python 常量回退。

## 4. 验证设计

- E015：手算公式一致；相同工况按压力梯度归一后床高尺度不变；标况流量翻倍使指数按 `2^-1.7` 变化；压力次序和零流量失败。
- E020：逐项气体×GWP 独立重算；分项和等于 scope 和且总量/信用量/分配闭合；单位错配、缺失因子和数据库不可用失败；对数据库记录携带 record ID、版本和校验和。
- F008：几何钢流量独立重算；两种模式在构造等价热负荷时给出相同总水量；多流股线性缩放；零温升和冲突模式字段失败。
- F018：Stokes 极限与解析式对照；终端浮力/阻力残差接近零；距离线性缩放；逆向流导致无法到达但仍返回合法运动学结果；密度顺序和 Re 超域失败。
- 接口：四项均从统一注册中心发现，逐项通过真实 HTTP function call 和隔离 forced route；provider case 文件只作调用冒烟，不属于研究数据集。
- 全量：新增专项、既有全部回归和基线统计全部通过；目标计数为 registered/qualified/fully eligible 105、目录覆盖 87、数据必需 35/合格 35。
