## 3. 统一工具契约

### 3.1 B012 绝热反应温度

- 输入：数据库反应式、反应前各物种摩尔数、初温、反应进度/转化率、求根温区；可选一个显式相变项。
- 输出：绝热终温、反应进度、反应前后组成、298 K反应焓项、反应物显热、产物显热、相变潜热、能量闭合残差、求根状态和记录级来源。
- 能量方程：

  `ξΔH°r,298 + Σ n_final[H_i(Tad)-H_i(298)] - Σ n_initial[H_i(Tin)-H_i(298)] + Qphase = 0`

- 适用域：单个已登记反应、固定压力、无外部热损、Shomate温区覆盖；首版至多处理一个已知温度和潜热的相变。
- 失败：未知反应/物种、进度造成负物质的量、温区无数据、根未被括住、相变字段不完整。
- 独立验证：能量残差；零转化时 `Tad=Tin`；增加惰性稀释使放热反应终温下降；无相变时与直接SciPy积分/手算复算。
- 关系：消费A006配平语义、B003/B006热物性与反应焓，和D002能量守恒重叠但不含转炉物流。

### 3.2 B013 理想气体混合平衡

- 输入：候选气体列表、初始各物种摩尔数、温度、压力、迭代上限和守恒容差。
- 输出：平衡摩尔数/摩尔分数、初末元素总量与残差、初末总Gibbs能、下降量、迭代与收敛状态、数据库来源。
- 目标：

  `min G/(RT)=Σ n_i[g°_i(T)/(RT)+ln(y_i P/P°)]`，约束 `A n=b, n_i≥0`，`P°=100000 Pa`。

- 适用域：理想气体、NASA7数据库物种、200–3500 K、最多12种物种和8种元素；不处理凝聚相、离子或真实气体逸度。
- 失败：候选物种无NASA7、初始物种未列入候选集、元素约束不可行、优化不收敛、守恒或Gibbs单调闸门失败。
- 独立验证：元素守恒；最终G不高于初态；水煤气变换的反应商与NASA7直接计算Kp一致；只有O2/N2时组成不变。
- 关系：组合A002元素解析与B002 NASA7，输出与B009平衡常数互相验证；区别于B012的指定反应固定进度能量平衡。

### 3.3 B016 Redlich-Kister超额Gibbs

- 输入：二元组成、温度、按 `L0,L1,...` 排列的J/mol系数、参数来源和版本。
- 输出：归一化组成、`GE`、偏摩尔超额Gibbs能、活度系数、活度、模型阶数和来源回显。
- 方程：`GE=x1x2 Σ Lk(x1-x2)^k`；由解析一阶导数计算两个偏摩尔超额量并令 `lnγi=μiE/(RT)`。
- 适用域：二元单相、调用者给定参数已适用于所给温度；首版系数不随温度变化。
- 失败：非二元、组成非法、系数空/非有限、参数来源或版本为空、指数溢出。
- 独立验证：只有L0时严格退化为B015；L全零退化为B014；`Σxi μiE=GE`；解析导数对照中心差分。
- 关系：B015是其0阶对称特例；与B014/B015相同输出但理论粒度不同。

### 3.4 B017 Henry/Raoult标准态切换

- 输入：稀溶质摩尔分数、温度、Raoult标准态活度/活度系数，及 `γ∞`；或用Henry常数与纯组元标准态逸度给出同一比值；必须带参数来源和版本。
- 输出：两标准态的活度、活度系数、标准化学势偏移、转换因子、稀释域警告和来源回显。
- 约定：`γ∞=H/f*`，`aH=aR/γ∞`，`γH=γR/γ∞`，`μH°−μR°=RT lnγ∞`，从而总化学势不变。
- 适用域：同一压力单位下的正数比值；Henry标准态只建议稀溶质 `x≤0.1`，超出时返回警告而不伪造精度。
- 失败：缺转换因子、H与f*单位/数值不合法、直接因子与H/f*不一致、来源字段缺失。
- 独立验证：Raoult→Henry→Raoult往返；直接γ∞与H/f*路径一致；两标准态总化学势相等。
- 关系：消费B014/B015/B016的Raoult基准活度输出；只做标准态变换，不拟合Henry参数。
