# P1-W9：67→74 工具实施蓝图

## 1. 范围与资格口径

本波新增 `C009`、`C010`、`E006` 简化变体、`E007`、`E009` 理论变体、`E012`、`E014`。目标是把注册数、运行时实现数和严格合格数从 67 提升到 74。严格对照主表后，C009/C010/E007/E012/E014可覆盖5个目录条目，主目录覆盖数从63提升到68；E006缺少主表要求的理想点/直接还原度，E009缺少经验标定/边际收益，二者只能标为 `scope_variant`，不得计入目录覆盖数。

七项都采用确定性公式或守恒算法，不需要新增依赖。它们必须具有独立执行代码、单位化 Schema、适用域、标准错误、来源版本、三项正常样例、至少两项边界/失败样例、独立数学验证和明确的上下游/重叠关系。不得把同一函数的别名或只改输出字段的包装器计数。

## 3. 七项工具设计

### C009 导热系数混合规则

- 科学作用：由各相导热系数和体积分数计算串联下界、并联上界；二相基体-球形夹杂时另算 Maxwell–Eucken 有效导热系数。
- 输入：`phases[{name, conductivity_w_m_k, volume_fraction}]`、`method`、二相模型可选 `matrix_phase`。
- 输出：有效导热系数、串/并联界、归一化体积分数和所用模型。
- 适用域：各相各向同性，体积分数和为 1；Maxwell–Eucken 只接受二相、连续基体和无接触球形夹杂，不含辐射、接触热阻或渗流。
- 依据：串并联热阻；Maxwell–Eucken 经典二相模型。
- 区别/关系：区别 T001 的已知 `k` 平板导热；C009 输出可作为 T001、F005 的材料输入，与未来数据库物性工具在输出上重叠。

### C010 填充床颗粒-流体传质系数

- 科学作用：由流速、粒径、密度、黏度和分子扩散系数计算 `Re`、`Sc`、`Sh` 和 `k_m`。
- 公式：Wakao–Funazkri，`Sh = 2 + 1.1 Re^0.6 Sc^(1/3)`，`k_m = Sh D/d_p`。
- 输入/输出：SI 制输入；输出无量纲数和 `m/s` 传质系数。
- 适用域：球形或等效球形颗粒填充床，`3≤Re≤10000`，属性在膜层尺度视为常数。
- 失败：非正物性/粒径、零流速、Re 超出关联式域。
- 区别/关系：区别 C002 的体相扩散系数；依赖 C002 或实测 `D`，可供 C006 缩核反应和后续炉内传质模型使用。

### E006 简化 C–O Rist 操作线

- 科学作用：按每 kmol Fe 的碳、氧守恒重建操作线 `Y = n_C^g X - n_O^B`，并用炉顶 CO/CO2 状态点校验闭合。
- 输入：铁基准、鼓风输入氧原子量、炉料 Fe 结合氧、炉顶 CO/CO2 量。
- 输出：斜率、截距、炉顶气 `O/C`、炉料 `O/Fe`、状态点预测值和闭合残差。
- 适用域：稳态、简化 C–O Rist 图；不包含 H2 注入、热约束、Si/Mn/P 还原和直接还原分解。扩展 Rist 不在本版本范围。
- 区别/关系：E003/E004 分别审计元素闭合；E006把这些量归一到 Fe 基准并形成操作线几何。E007 可在后续为操作线增加热约束。

### E007 高炉两区静态热平衡

- 科学作用：对高温区、低温区两个控制体计算显热/反应热/相变热/热损失及区间热传递的闭合。
- 输入：铁水产量、两区显式热输入项和热输出项、从高温区传向低温区的界面热量、容差。
- 输出：各区和全炉输入/输出、残差、每吨铁指标与是否闭合。
- 适用域：同一稳态统计基准，所有上游焓项已由 B003/B006 等工具或实测数据统一到 kJ；不根据温度暗算缺失物性。
- 区别/关系：区别 D002 的 BOF 装料-终温模型；本工具是 BF 两区控制体闭合审计，依赖 B003/B006/T001/T002 的热项。

### E009 喷煤理论等效替代

- 科学作用：按固定碳当量、低位热值当量或二者共同限制，计算喷煤可替代的焦炭量。
- 输入：喷煤量、煤/焦固定碳质量分数、煤燃尽率、煤/焦 LHV、两者有效热利用率、选择的理论基准。
- 输出：碳基替代比、热值基替代比、所选理论替代比、替代焦量和未燃碳。
- 适用域：理论静态当量；不声称预测实际高炉焦比变化。实际替代率还受炉况、灰分、挥发分、渣量和透气性影响。
- 区别/关系：与 E003 碳平衡和 E007 热平衡重叠；输出可供 E001/E003 的方案物流使用。

### E012 风口前理论煤气量

- 科学作用：按干鼓风、富氧、鼓风水分和喷吹燃料元素量进行 C/H/O/N 原子平衡，计算 O 全部转为 CO 时的理论风口煤气组成和体积。
- 输入：干鼓风和富氧标况体积、干风 O2 体积分数、水蒸气 kmol、燃料元素 kmol、标况摩尔体积。
- 输出：CO/H2/N2 理论 kmol 与 Nm3、组成、所需碳、未反应碳及四元素残差。
- 适用域：风口回旋区理论完全耗氧、产物限定为 CO/H2/N2；不含 CO2、CH4、硫物种、灰分气化、漏风或上升过程反应。
- 区别/关系：依赖 A006/A007 的计量约束，并与 E003/E004/E005 的下游元素平衡形成可执行链。

### E014 料柱 Ergun 压降

- 科学作用：计算填充料柱黏性项、惯性项和总压降。
- 公式：`ΔP/L = 150 μu(1-ε)^2/(ε^3 d_eff^2) + 1.75ρu²(1-ε)/(ε^3 d_eff)`，`d_eff=φd_p`。
- 输入/输出：SI 制粒径、球形度、孔隙率、表观速度、气体密度/黏度、床层高度；输出 Pa/m、Pa 和颗粒 Reynolds 数。
- 适用域：稳态单相不可压或以平均物性近似的填充床；不含软熔带收缩、粒径分布、非均匀布料和壁面效应。
- 区别/关系：与 C010 共用粒径/流体物性但目标不同；可作为高炉压差诊断的原子工具。

## 4. 来源版本

- Maxwell–Eucken：经典基体-球形夹杂解析模型；NASA 关于多孔填充床有效导热率的公开技术文献用于模型边界复核。
- Wakao & Funazkri, *Chemical Engineering Science* 33 (1978) 1375–1384，DOI `10.1016/0009-2509(78)85120-3`。
- Rist 图：Geerdes et al., *Modern Blast Furnace Ironmaking* 的附录 C/O 平衡；以及最新扩展 Rist 公开论文用于确认简化模型的限制。
- BF 风口煤气：公开论文中的鼓风/富氧/喷吹物元素守恒形式。
- Ergun, “Fluid Flow Through Packed Columns”, *Chemical Engineering Progress* 48 (1952) 89–94。
- 热平衡、碳守恒与理想气体换算遵循热力学第一定律、元素守恒和标况摩尔体积定义。
