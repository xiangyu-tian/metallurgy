## 2. 工具身份和科学实现

- 模型：`F007 结晶器热流计算`。
- 不可变身份：`metallurgy.catalog.f007.mold_heat_flux.v1`。
- 大模型函数：`metallurgy_calc_mold_heat_flux`。
- 实现位置：`Tools/models_core/models_f.py`。
- 公式：

```text
Qdot_i = mdot_i * cp_i * (T_out_i - T_in_i)
Qdot_total = sum(Qdot_i)
q_mean = Qdot_total / A_effective
heat_removed_per_steel_mass = Qdot_total / mdot_steel  # 仅调用者显式提供钢质量流量时
```

首版只认证冷却水侧显热平衡。它返回水侧平均移热，不宣称是铜板局部峰值、弯月面瞬态热流、热电偶反演或经验关联结果。

公开依据：

- ISIJ International 63(8), 2023, Eq. (15)：`https://www.jstage.jst.go.jp/article/isijinternational/63/8/63_ISIJINT-2023-051/_html/-char/en`。
- IAPWS R2-83(1992)水临界温度647.096 K：`https://iapws.org/documents/release/crits`。

## 3. Schema、单位和失败边界

必填输入：

- `cooling_circuits[]`：每回路必须有唯一 `circuit_id`、`mass_flow_kg_s`、`inlet_temperature_k`、`outlet_temperature_k`、`water_specific_heat_j_kg_k`、非空 `measurement_source`。
- `effective_heat_transfer_area_m2`：必须大于0。
- `area_definition`：非空面积口径，如 `broad_face`、`narrow_face` 或 `whole_mold`。
- 可选 `steel_mass_flow_kg_s`：提供时必须大于0，工具才返回单位钢质量移热；不提供时两个相关输出为JSON `null`，输出Schema显式声明 `number|null`。

输出包括：逐回路温升、移热率和贡献率，总移热率、平均热流密度、单位钢质量移热、回路求和残差、测量来源、面积口径和计算方法版本。

边界和失败：

- `T_out=T_in`：成功返回零移热，同时给传感器分辨率/时间窗同步警告。
- `T_out<T_in`：`OUT_OF_DOMAIN`；首版没有反向换热模式。
- 非正流量、比热、绝对温度、面积或钢质量流量：拒绝。
- 水温达到或超过647.096 K：`OUT_OF_DOMAIN`；首版只适用无相变冷却水。
- 回路字段缺失、未知字段、重复回路编号或空来源：`INVALID_INPUT`。

## 4. 关系与目录映射

- 与T001真实重叠：二者都返回热流率/热流密度；T001由导热系数、厚度和温差求平板稳态导热，F007由冷却水量热求结晶器平均移热。
- 与T002互补：T002是指定表面间的灰体辐射项，F007是结晶器水侧总体平均量热。
- F007输出可作为未来F005表面热流边界；主表交叉映射记录F005/F006关系，但因两项尚未注册，不把它们伪装成当前运行时依赖。
- 新增 `tool_catalog_crosswalk_v6.json`，完整唯一覆盖43个运行时资产；F007按 `same` 覆盖主表F007，目录覆盖由38增至39。

## 5. 独立验证和测试

F007模型卡包含3个正常、1个边界、2个失败准入用例；资格闸门实际报告3个正常和3个边界/失败通过。

独立验证：

1. 单回路手算：`10 kg/s × 4200 J/(kg·K) × 5 K = 210000 W`。
2. 两回路手算：`210000 W + 84000 W = 294000 W`；`294000/3 = 98000 W/m²`。
3. 替代比热：`12.5 × 4180 × 6 = 313500 W`；除以 `1.5 m²` 得 `209000 W/m²`。
4. 分别将质量流量、比热、温升加倍时总移热率加倍；面积加倍时热流密度减半。
5. 把单回路拆成两个半流量回路，总移热不变；`energy_sum_residual_w=0`。
6. 给定 `mdot_steel=2 kg/s` 时，单位钢质量移热为 `210000/2=105000 J/kg`。
