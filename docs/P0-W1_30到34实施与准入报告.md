## 4. 单项实现与验证

### 4.1 A101 / 表格A007 电荷与价态平衡

- 实现：解析化学式计量数；价态可按元素给单值，也可按位点给 `[{oxidation_state,count}]`，支持Fe3O4等显式混合价态。
- 输出：逐元素电荷贡献、计算电荷、目标电荷、残差、是否平衡、是否混合价态。
- 适用域：不从晶体结构或名称猜测价态；混合价态必须显式拆分，价态范围限[-8,8]。
- 失败：价态映射缺失/多余、位点计量不闭合、非有限数值、化学式非法。
- 依据：IUPAC oxidation state/electroneutrality；`q=Σn_i z_i`。
- 独立验证：Al2O3、NaCl、SO4²⁻；Fe3O4位点重排不变；错误FeO价态返回边界不闭合。
- 重叠：依赖A002；区别A006反应配平；是旧A007电子当量的价态校验上游。

### 4.2 A008 缺失值处理

- 实现：`constant/mean/median/most_frequent/linear/knn` 六种确定性方法；返回原始缺失掩码、逐列统计或逐格KNN供体记录。
- 输出：填补矩阵、缺失掩码、列名/单位、统计记录、填补数、剩余缺失数和警告。
- 适用域：二维数值表；v1不做分类变量、监督模型或生成式填补。
- 失败：矩阵不规则、列/单位不完整、整列缺失、线性插值观察点不足、KNN无共同观察特征。
- 依据：公开简单填补/线性插值/nan-aware欧氏距离算法；实现使用现有NumPy，不依赖scikit-learn运行时。
- 独立验证：非缺失观察值逐位不变；无缺失输入幂等；均值人工复算；KNN样本置换不变；全空列失败。
- 重叠：与A004分别负责缺失处理和尺度归一化；不在下游模型内部隐式执行。

### 4.3 D021 / 表格D001 转炉装料物料平衡

- 实现：按 `per_heat/per_t_steel/per_hour` 统一基准审计BOF输入/输出物流，或用指定元素求唯一未知输出物流质量。
- 输出：规范化物流、逐元素输入/输出/残差、总质量闭合、钢水收得率和求解记录。
- 适用域：零维静态完全混合；全部成分、去向和收得结果显式输入；最多一个未知输出质量。
- 失败：物流质量/成分非法、多未知欠定、求解元素含量为零、产生负质量解、基准不明确。
- 依据：总质量和逐元素守恒。
- 独立验证：Fe/C闭合炉次；整体缩放不变；单未知解代回Fe方程；缺失去向形成真实边界残差；负解失败。
- 重叠：比A005增加BOF物流类别、收得率与求解语义；与旧D001理论耗氧目标不同；输出可进入D002/D004。

### 4.4 D004 石灰/白云石加入量

- 实现：联立 `CaO_f-B·SiO2_f=0` 与 `MgO_f-f_MgO·m_slag,f=0`，求石灰和白云石非负加入量。
- 输出：两种熔剂加入量、预计氧化物质量和总渣量、实际碱度/MgO、残差、约束行列式。
- 适用域：完全混合、给定入渣利用率；化验质量分数必须闭合，不模拟溶解动力学或喷溅。
- 失败：化验不闭合、矩阵奇异、目标产生负加入量、最终SiO2/渣量为零。
- 依据：氧化物质量守恒和CaO/SiO2二元碱度定义。
- 独立验证：解代回两条约束；原渣同比缩放时加入量同比缩放；零加入边界；相同熔剂化验导致奇异失败。
- 重叠：是D021全炉平衡中的熔剂子问题；输出可进入D002热平衡。
