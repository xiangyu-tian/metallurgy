## 4. W5A：F007结晶器热流计算

### 4.1 科学实现

首版固定为冷却水侧显热平衡：

```text
Q_dot_i = m_dot_i * cp_i * (T_out_i - T_in_i)
Q_dot_total = sum(Q_dot_i)
q_mean = Q_dot_total / A_effective
```

所有物性和测量值由调用者显式输入；不内置水密度、比热、有效面积或设备常数。因此首版为 `FORMULA_ONLY`，不需要数据库迁移。

### 4.2 输入Schema

- `cooling_circuits[]`：`circuit_id`、`mass_flow_kg_s`、`inlet_temperature_k`、`outlet_temperature_k`、`water_specific_heat_j_kg_k`、`measurement_source`。
- `effective_heat_transfer_area_m2`：本次核算采用的有效面积，必须显式提供。
- `area_definition`：`broad_face`、`narrow_face`、`whole_mold`或调用者定义说明。
- 可选 `steel_mass_flow_kg_s`：用于计算单位钢质量移热，不提供则不推断。

### 4.3 输出Schema

- 各回路 `heat_rate_w`、温升和贡献率。
- `total_heat_rate_w`、`mean_heat_flux_w_m2`。
- 可选 `heat_removed_j_kg_steel`。
- 输入基准、面积口径、测量来源、能量求和残差和边界警告。

### 4.4 适用域与失败

- 适用于稳态时间窗平均值；不代表铜板局部峰值热流或弯月面瞬态波动。
- 流量、比热和面积必须为正；温度必须高于绝对零度。
- `T_out=T_in` 返回零热流和传感器/时间窗边界警告。
- `T_out<T_in` 默认返回 `OUT_OF_DOMAIN`，除非未来增加明确的反向换热模式。
- 不接受体积流量后静默套用固定水密度；体积流量路径需另行引入水物性Repository。

### 4.5 资格验证

- 3个正常：单回路手算、多回路求和、给定钢质量流量的单位质量移热。
- 2个边界/失败：零温升警告；负温升或非正面积失败。
- 独立性质：对流量、比热、温差线性；回路和等于总量；总热流除面积等于平均热流密度。
- 统一接口名：`metallurgy_calc_mold_heat_flux`。

## 5. W5B：F005一维坯壳厚度

### 5.1 科学实现

求解表面到铸坯中心的一维瞬态能量方程：

```text
rho(T) * c_eff(T) * dT/dt = d/dx [ k(T) * dT/dx ]
c_eff(T) = cp(T) + L * |dfs/dT|
```

- 空间离散：单元中心有限体积；表面为给定热流或换热边界，中心为对称零通量。
- 时间离散：隐式Euler作为资格基线；温变物性/等效比热使用Picard迭代并报告迭代残差。
- 坯壳定义：由显式 `shell_solid_fraction_threshold` 定义，默认值不得隐藏；沿网格插值求厚度。
- SciPy只作为直接、精确固定版本的数值依赖；实施时将当前验证版本写入requirements。FiPy可作参考实现验证，不作为首版运行依赖。

### 5.2 数据资格前置条件

现有PostgreSQL只登记了DS031、DS035、DS036、DS037、DS042资料源，没有可执行的钢种物性、设备或边界记录。F005在以下数据闭环完成前不得注册为合格工具：

1. 版本化钢种物性：`rho(T)`、`cp(T)`、`k(T)`、潜热、固/液相线或焓曲线。
2. 物性单位、温区、相态、成分/钢种、来源、版本和不确定度。
3. 至少一个公开、可复核的基准物性集。建议首个基准采用NIST SRM 316L公开热物性论文中的密度、焓/热容及1675/1708 K固液相端点；它只用于其声明域，不外推为通用钢种。
4. 企业DS042数据只有在得到授权、脱敏和数据字典后才能导入；不能用占位数据冒充。
5. 导入前执行全库备份、恢复演练、迁移dry-run和insert-only冲突检查。

### 5.3 拟新增数据库对象

- `casting_material_property_set`：物性集ID、钢种/成分、来源数据集、版本、温区、批准状态。
- `casting_material_property_correlation`：`DENSITY`、`HEAT_CAPACITY`、`THERMAL_CONDUCTIVITY`、`ENTHALPY`、`LATENT_HEAT`等方程与系数、单位和温区。
- `casting_boundary_profile`：经过授权的热流/换热系数随时间或轴向位置曲线；记录设备和测量来源。
- `casting_model_benchmark_case`：解析解、实验数据或批准参考实现输入、期望值和容差。

运行时只通过Repository读取批准记录并返回记录级溯源；缺数据、超温区或自然键冲突时失败，不回退到Python常量或隐藏JSON。

### 5.4 输入/输出

输入：半厚度、初始温度或F003结果、总时间/轴向位置、拉速、网格与时间步长、物性集ID、表面边界、固相率阈值；固相率可接受F004曲线及其上游执行ID。

输出：温度剖面、固相率剖面、坯壳厚度—时间/位置曲线、表面/中心温度、累计移热、显热/潜热变化、能量闭合误差、非线性收敛和网格信息。

接口名：`metallurgy_solve_1d_shell_growth`。

### 5.5 资格验证

- 常物性、无潜热退化到一维导热解析解。
- 半无限体定热流/定表温问题与解析解对照。
- `fs+fl=1`、温度和固相率物理边界、累计移热与焓变闭合。
- 网格和时间步加密后坯壳厚度变化小于批准容差。
- 零热流保持初始温度；提高外向热流不应减慢坯壳生长。
- 3个正常、至少1个网格边界和1个缺数据/超域失败。

## 6. W5C：F006凝固终点预测

### 6.1 首版定位

首版只实现物理数值路径，不训练回归代理。输入F005产生的中心固相率—时间/轴向曲线或由F006内部以同一批准配置调用F005；根据显式阈值寻找首次满足：

```text
fs_center(z) >= endpoint_solid_fraction_threshold
z = casting_speed * t
```

在阈值两侧温点/位置间插值，返回数值分辨率和插值区间。代理模型留待DS042历史浇次数据具备训练、验证、漂移和OOD治理后再设计，不能先放空模型卡。

### 6.2 数据与数据库

除F005物性和边界记录外，还需：

- `casting_machine_configuration`：设备ID、断面、结晶器长度、二冷分区、有效冶金长度、配置版本和批准状态。
- `casting_run_condition`：经授权的钢种、拉速、过热度、水量及时间窗；首版可由调用者显式输入，按浇次查询模式必须使用Repository。
- 不允许硬编码某厂机长、拉速范围、二冷水量或经验安全余量。

### 6.3 输出与失败

输出：凝固终点距离、对应时间、阈值、插值区间、数值不确定度、设备内/设备外状态、出口中心固相率、F005上游执行ID和数据溯源。

失败：曲线未跨越阈值、轴向/时间不单调、缺F005执行ID、拉速/设备长度非法、模型配置与浇次配置不匹配。

接口名：`metallurgy_predict_solidification_end`。

### 6.4 资格验证

- 人工构造线性固相率曲线，手算阈值交点。
- 时间—距离满足 `z=v*t`，单位路径一致。
- 阈值变化产生正确单调趋势；网格加密后终点收敛。
- F005→F006端到端调用链保留两个执行ID和数据来源。
- 3个正常、曲线端点恰好等于阈值的边界、未跨阈值/配置不匹配失败。

## 7. 统一API和大模型调用规则

三项均通过现有统一接口暴露：

```http
GET /api/v1/tools?fully_eligible=true
POST /api/v1/tools/{function.name}/call
```

- 工具定义必须含不可变 `tool_uid`、目录ID、版本、JSON Schema、单位、适用域、来源、失败码、依赖和关系。
- 大模型调用时，F007允许单工具强制调用；F005需明确物性集和边界来源；F006需明确F005上游执行ID或完整自动求解配置。
- 每波只对新工具做隔离强制function-call测试：函数名、参数Schema、执行结果、科学检查、`execution_id`和`model_code`回传全部通过。
- 不以自主选择测试代替逐工具可调用性测试；不把接口冒烟用例扩张成正式研究数据集。
