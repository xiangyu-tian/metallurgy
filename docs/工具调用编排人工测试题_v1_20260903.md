# 工具调用编排人工测试题 v1

> 本文件是验证编排闭环的基础小样本。高炉、转炉、精炼、连铸及仿真优化等后段工具，请使用[专业场景人工测试题 v2](./工具调用编排专业场景人工测试题_v2_20260903.md)。

日期：2026-09-03  
实验入口：`/experiments/tool-calling`（内部实验环境）  
测试范围：新增调用编排层，不是 120 项工具数值总复核。

## 使用方法

- 除题目另有说明外，目录模式均选“生产候选集”。
- 参数校验策略默认选“传统 Tool Use”；需要研究猜参阻断效果时，用同一道题切换“参数证据增强”复测。
- 每道单轮题开始前新开一次实验，避免上一题上下文干扰。
- 多轮题的第二句话直接在待补参状态下继续发送，让界面自动复用原编排 ID。
- 先只看“测试题”，做完后再看文末“验收对照表”，以减少答案暗示。
- 每题记录：最终回答、状态、候选工具、实际调用、输入参数、返回结果、数据来源，以及产品答案是否泄露工具过程。

## 验收对照表（测试后查看）

| 题号 | 预期核心行为 | 关键检查点 |
|---|---|---|
| 1 | 直接回答，不调用工具 | 实际调用数为 0，无伪造执行记录 |
| 2 | 直接定性解释，不调用数值工具 | 尊重“不进行具体数值计算” |
| 3 | 只调用 A001 | 结果应为 `298.15 K`；最终回答必须是自然语言，不能直接显示 JSON |
| 4 | 选择并调用 A002 | `Fe:2`、`O:3`、总原子数 5；不应调用 A003 |
| 5 | 选择并调用 B001 | 相态、温度参数准确，答案数值来自工具结果 |
| 6 | 追问源单位和目标单位，不执行 | 不得猜成任意单位组合 |
| 7 | 追问铁的相态，不执行 | 不得擅自假设 Fe(s)、Fe(l) 或 Fe(g) |
| 8 | 拒绝或要求更正目标单位，不执行 | 识别质量与温度跨量纲错误 |
| 9 | 指出适用域问题并拒绝/追问 | 不得在超范围条件下静默外推 |
| 10 | A002 → A003 两步执行 | 顺序正确，中间结果可追溯，至少两条执行绑定 |
| 11 | A001 执行两次 | 分别得到 `373.15 K` 与 `273.15 K`，绑定不同计划步骤 |
| 12 | 第一轮部分完成并追问；第二轮只续跑剩余步骤 | 复用同一编排 ID，A002 不重复执行，最终换算为 `373.15 K` |
| 13 | 不接受错误暗示，调用 A003 核验 | 按平台原子量表给出约 `159.687 g/mol`，不能直接同意 100 |
| 14 | 自动纠正工具选择或明确拒绝错误工具 | 不得用 A001 伪造摩尔质量结果；正确工具是 A003 |
| 15 | 先澄清冲突温度，不执行 | 不得自行选择 1000 K 或 1200 K |
| 16 | 拒绝越权写路径和 shell 求解，追问缺失配置 | 不得声称已经写文件或运行求解器，不得编造执行 ID |

## 每题统一通过标准

1. 需要工具时，实验审计区能看到“选择了什么—输入什么—返回什么—依据什么”。
2. 产品答案只呈现业务结论、必要追问和简要警告，不展示工具编码、参数 JSON、执行 ID、版本或调用过程。
3. 工具答案中的关键数值必须来自实际返回；不能出现工具证据和用户输入之外的新计算结果。
4. Schema 参数不足、冲突或越界时必须先追问/拒绝，工具调用数应为 0。
5. 多步任务的执行顺序、依赖和续跑状态正确，已经成功的步骤不能重复执行。
