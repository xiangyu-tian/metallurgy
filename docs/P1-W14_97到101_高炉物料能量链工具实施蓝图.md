# P1-W14：97→101 高炉物料—能量链工具实施蓝图

## 1. 波次目标与边界

本波只新增并认证 `E106`、`E109`、`E010`、`E013` 四项运行时工具，使注册数和严格合格可执行数由 97 提升到 101，主能力目录覆盖数由 79 提升到 83。既有 `E006` 简化 C–O Rist 线、`E009` 理论碳/热值替代、`E012` 风口前理论煤气和 `B012` 通用单反应绝热温度保持原样。

本波不读取现场传感器、不训练模型、不生成正式研究数据集、不调用外部大模型 API。四项只处理调用方明确给出的同一统计基准；任何缺项、物理不可行、元素或能量不闭合、超关联式温区均显式失败或返回边界告警。数据库只读复用已批准的 `DS_NASA7_GRI30`，不迁移、不插入、不更新和不删除既有记录。

## 3. 科学定义、Schema 和适用域

### 3.1 E106 完整物料型 Rist 操作线

- 主要输入：Fe 基准、炉料与铁水氧量、炉顶 `CO/CO2/H2/H2O`、能量平衡固定点 P、理想 Fe–wüstite 点 W、闭合容差。
- 核心式：`X=(O+H/2)/(C+H/2)`，`Y=O/Fe`，`Y=μX+Y_E`，`y_d=μ+Y_E`。实际线由炉顶点 A 与 P 构造；理想线由 W 与 P 构造。
- 主要输出：A/P/W 坐标、实际/理想斜率和截距、炉顶气独立复算的 `μ`、直接/间接还原氧、直接还原分数、实际相对理想的还原剂超额、直线端点和闭合状态。
- 适用域：稳态、上部无中途注入/碳酸盐分解释放造成的未登记气体源；P 和 W 必须由同一坐标定义及同一 Fe 基准给出。当前版本是完整的物料—理想点 Rist 工具，不自行求解全炉热平衡点 P。
- 依据：Rist 操作图的广义 C–H–O 坐标、操作线斜率与直接还原关系；公开复核来源为 [Revisiting the Rist diagram for predicting operating conditions in blast furnaces with multiple injections](https://pmc.ncbi.nlm.nih.gov/articles/PMC10445826/)。
- 关系：依赖 E001–E005 的基准与元素量，E011 可提供气体利用率，E007 可提供/审核 P 点；与 E006 是相同任务不同粒度的真实重叠。

### 3.2 E109 完整 PCI 置换与边际账

- 主要输入：喷煤量、基准焦比、最低结构焦比、煤/焦固定碳、灰分、LHV、燃尽率/有效热利用率、煤焦工艺热需求和允许的增量灰分。
- 核心式：分别计算有效固定碳置换上限、净有效能置换上限和最低结构焦比上限，选择三者最小值；随后独立回代碳裕量、热裕量和灰分增量。
- 主要输出：三种上限、控制约束、等效焦炭替代量、替代后焦比、总燃料变化、碳/热裕量、未燃碳、增量灰分和可行性。
- 适用域：静态单工况、调用方提供已确认的煤焦分析与有效系数；不把理论边际量解释为现场实测焦比，不预测透气性和炉况动态。
- 依据：固定碳与净有效能守恒、结构焦比和灰分显式约束；公开物料平衡交叉参考为 [Material Balance in a Blast Furnace, when Replacing Coke with Coal Dust](https://www.gup.ugal.ro/ugaljournals/index.php/mms/article/view/1129)。
- 关系：依赖 E003 的碳账、E007 的热账、E005 的含氢燃料边界；与 E009 输出目标相同但约束和输出粒度不同。

### 3.3 E010 理论炉顶煤气组成

- 主要输入：风口气 `CO/H2/N2`、被还原矿石氧、直接还原分数、间接还原中 H₂ 分担率、外加 `CO2/H2O/N2` 和标况摩尔体积。
- 核心式：直接还原每移除 1 kmol O 生成 1 kmol CO；间接还原按给定 H₂ 分担率把 CO/H₂ 等摩尔转为 CO₂/H₂O；N₂ 作为惰性示踪。逐项独立复算 C/O/H/N 残差。
- 主要输出：各组分 kmol/Nm³、湿基和干基组成、CO/H₂ 利用率、直接/间接还原量、四元素残差、总炉顶气量。
- 适用域：稳态理论气体，物种限定 `CO/CO2/H2/H2O/N2`；不含 CH₄、漏风、粉尘碳、碳酸盐分解以外未声明气源。
- 依据：C/O/H/N 元素守恒和间接还原等摩尔转换；公式结构可与 [ISIJ International 63(5), top-gas Eqs. 46–52](https://www.jstage.jst.go.jp/article/isijinternational/63/5/63_ISIJINT-2022-505/_html/-char/ja) 交叉验证。
- 关系：E012→E010 形成风口气到炉顶气链；E003/E004/E005 分别审核 C/O/H；E011 与本工具计算的利用率重叠。

### 3.4 E013 风口回旋区绝热火焰温度

- 主要输入：干鼓风量与 O₂ 分数、富氧量、鼓风/富氧温度、蒸汽量与温度、实际参与气化的燃料 C/H/O/N 原子量、该反应燃料的有效 LHV、燃料显热和显式工艺吸热、求根上下界。
- 核心式：先按 E012 同口径生成 `CO/H2/N2`；以燃料完全氧化 LHV 减去产品 CO/H₂ 保留化学能，叠加热风/富氧/蒸汽/燃料显热并扣除工艺吸热；用 PostgreSQL 中 `DS_NASA7_GRI30` 的 NASA7 焓增量求解 `Σn_p[h(T)-h(298)]=Q_available`。
- 主要输出：RAFT、产品气组成、化学放热/保留化学能/各股显热/工艺吸热、产物显热、能量残差、迭代状态和记录级来源。
- 适用域：绝热、定压、完全耗氧且参与反应的碳恰好生成 CO；物种限定 `O2/N2/H2O/CO/H2`，200–3500 K。煤热解、灰分加热等必须通过显式工艺吸热输入，不能暗用企业经验系数。
- 依据：回旋区热量守恒与理论燃烧温度形式可由 [ISIJ International 63(5), Eq. 62](https://www.jstage.jst.go.jp/article/isijinternational/63/5/63_ISIJINT-2022-505/_html/-char/ja) 复核；物性使用已入库 GRI-Mech 3.0 NASA7 固定版本。
- 关系：复用 E012 的原子守恒口径，但独立实现并加入能量方程；与 B012 同为绝热温度，但 B012 处理单个登记反应，本工具处理 BF 风口多股物流和保留化学能。

## 4. 数据、依赖和实现顺序

- E106、E109、E010 为 `FORMULA_ONLY`，所有工况量由调用方显式提供。
- E013 为数据必需型，只读 `metallurgy_v2.thermodynamic_correlation` 中现有 `DS_NASA7_GRI30` 的 12 条记录；运行时必须经 Repository 返回记录级 provenance。数据库关闭、记录缺失或温区超界均失败，不做 Python 常数兜底。
- 不新增 Python 依赖；求根使用标准库二分法，数据库层沿用受管 `psycopg2`。
- 实现顺序：E010（物料链终点）→E106（Rist 几何和直接还原）→E109（PCI 完整约束）→E013（数据库焓和求根）→统一注册与目录交叉映射→专项和全量测试→Excel/Markdown 主目录同步。

## 5. 准入、验证与停止条件

每项至少内置 3 个正常样例和 2 个边界/失败样例，并通过：

1. 输出字段与单位严格匹配 Schema，标准错误码可稳定复现；
2. E106 的两点直线、`μ` 独立气量复算和 `y_d=μ+Y_E` 性质；
3. E109 的碳/热/结构三上限、边际质量账和灰分账独立回代；
4. E010 的 C/O/H/N 四元素残差、湿/干组成归一及线性缩放；
5. E013 的 NASA7 独立焓回代、热风升温使 RAFT 上升、增加显式吸热使 RAFT 下降、数据库关闭失败；
6. 统一注册中心、HTTP 直接调用和本地 `forced` 路由逐项成功；
7. 全量现有回归通过，计数动态报告为注册 101、严格合格 101、目录覆盖 83、数据必需/合格 34/34；
8. Excel 主目录与 Markdown 镜像一致，仍保持 `101 已实现 + 17 后续保留 + 2 新增替换 = 120`。

若任何工具无法满足物料/能量守恒、E106 的实际线与气量不一致、E109 的灰分或结构焦比不可行、E010 还原气不足、E013 无法在批准温区括住能量根，则该项不得 `count_eligible=true`，按实际通过数量报告并停止。本波完成、提交并推送后停止，不自动实现 E015/E020 或其他下一批能力。
