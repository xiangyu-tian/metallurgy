# 120 工具文件产出能力审计（2026-09-03）

## 结论

当前 120 个合格工具均可形成可回读的文件产物，但必须区分两种不同语义：

1. **原生科学文件产物**：仅 G005。OpenFOAM 案例目录本身就是该工具的核心计算产物，可直接交给 `blockMesh` 和 `laplacianFoam`。
2. **执行结果文件包**：其余 119 项。工具的核心产物仍是数值结果；文件包只是对同一结果的无损落盘，供人工复核、绘图、归档和下游程序读取，不作为新工具计数。

不应要求每个工具都伪造一个“案例工程”。曲线、时序、批处理、优化、平衡清单等结果适合默认提供 CSV/JSON；单一标量或短对象适合按需导出 JSON。这样既有具体文件，也不改变科学定义或制造重复包装工具。

| --- | ---: | --- |
| 原生案例包 | 1 | G005 通过 `arguments.artifact_mode` 生成 OpenFOAM 目录、manifest 和可选 ZIP |
| 建议生成结果包 | 30 | 曲线、时序、批量、优化、平衡和审计型输出，顶层数组自动生成 CSV |

能力清单可通过 `GET /api/v1/artifacts/capabilities` 读取；`GET /api/v1/tools` 中每个工具也带有 `artifact_capability`。

## 文件包契约

非 G005 工具可在调用时直接要求文件产出：

```json
{
  "arguments": {"...": "工具原有输入"},
  "options": {
    "validate_boundary": true,
    "return_provenance": true,
    "artifact": {
      "mode": "directory_and_zip",
      "name": "review_case_01"
    }
  }
}
```

也可先正常执行，再通过 `POST /api/v1/executions/{execution_id}/artifact` 对成功记录补生成文件包：

```json
{
  "mode": "directory_and_zip",
  "name": "review_case_01"
}
```

已生成 ZIP 的执行记录可通过以下相对地址下载，不接受调用方传入文件系统路径：

```text
GET /api/v1/executions/{execution_id}/artifact/download
```

下载前服务端会重新检查执行状态、工具固定输出根目录、普通文件类型和 SHA-256。响应包含 `Content-Disposition`、`Content-Type: application/zip` 与 `X-Artifact-SHA256`。Node 代理保留这些响应头并以二进制转发，避免把 ZIP 错误解析为 JSON。

实验接口 `POST /api/v1/experiments/run` 同样接受可选字段：

```json
{
  "artifact": {
    "mode": "directory_and_zip"
  }
}
```

当选中 G005 时，该选项映射到原生 `artifact_mode`；其他工具使用统一执行结果包。前端不再需要理解两种后端实现细节。

每个通用结果包包含：

- `input.json`：原始执行输入；
- `result.json`：与 API 科学输出逐值相等的完整结果；
- `provenance.json`：数据来源、公式或模型版本记录；
- `README.md`：工具、版本、执行编号和文件解释；
- `manifest.json`：输入、结果和逐文件 SHA-256；
- `tables/*.csv`：每个顶层数组结果的 UTF-8 表格表示；
- `<name>.zip`：选择 `directory_and_zip` 时生成的确定性压缩包。

G005 不使用上述通用包装，而继续使用原生参数：

```json
{
  "arguments": {
    "case_name": "slab_heat_01",
    "artifact_mode": "directory_and_zip",
    "...": "G005 其余网格、边界和时间参数"
  }
}
```

## 安全和停止条件

- 输出根目录固定为项目内 `outputs/tool_artifacts/<tool-id>/`；调用者不能传任意文件系统路径。
- 文件名仅允许字母、数字、点、下划线和连字符，拒绝路径穿越。
- 文件先写临时目录并完整回读，再原子替换到目标名称。
- 同名、同内容可幂等复用；同名、不同内容拒绝覆盖。
- ZIP 使用固定时间戳、排序和权限生成，便于复现和哈希比较。
- 结果必须是有限 JSON；NaN、无穷或不可序列化对象拒绝落盘。
- G005 原生案例与通用结果包互斥，防止同一工具出现两套含义不一致的产物。
