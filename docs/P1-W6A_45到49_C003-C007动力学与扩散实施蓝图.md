# P1-W6A：45→49 动力学与扩散工具实施蓝图

## 1. 范围与计数

本波只新增4个真实可执行工具，不修改现有数据库、不导入材料常数、不生成研究数据集：

| 运行时码 | 表格目录码 | 能力 | 计数方式 |
| --- | --- | --- | --- |
| C103 | C003 | 一维 Fick 数值扩散 | 新实现；覆盖目录 C003 |
| C005 | C005 | 晶粒长大动力学 | 新实现；覆盖目录 C005 |
| C006 | C006 | 球形颗粒缩核反应 | 新实现；覆盖目录 C006 |

原运行时 C003 是常扩散系数、半无限体、恒表面浓度解析解，继续作为独立工具保留；它与目录 C003 所要求的一维有限域数值 PDE 不等价。为避免覆盖旧 API 和重复身份，数值工具使用运行时码 `C103`，但交叉映射到唯一目录码 `C003`。验收目标为：`registered_count=49`、`qualified_executable_count=49`、`catalog_coverage_count=45`，数据必需型工具仍为21项。

## 2. 数据边界与安全策略

- 四项均为 `FORMULA_ONLY`：公式/数值算法随代码版本化，材料参数由调用者显式提供。
- C005、C007 必须接收 `parameter_source` 和 `parameter_version`；C006 的传质、反应、扩散参数也不提供材料默认值。
- 参数来源字段用于结果追踪，不等同于平台批准数据库记录；结果必须明确标记为“调用者参数”。
- 本波不新增 SQL、不执行迁移、不写 PostgreSQL、不改已有数据表，因此没有破坏既有数据库的写路径。
- SciPy 已在受管 `Tools/requirements.txt` 中固定为 `1.18.1`，C103 使用其带状线性方程求解器，不安装新依赖。

## 3. 工具契约

### C103：一维 Fick 数值扩散

- 科学作用：求解有限一维域中的 `∂C/∂t=∂/∂x(D(t,x)∂C/∂x)`。
- 输入：域长、网格数、总时长、时间步、初始浓度数组、分段时间/空间扩散系数、左右定浓度或零通量边界、浓度单位。
- 输出：单元中心坐标、终态浓度、抽样历史、左右边界通量、初末库存、累计净边界传递、守恒残差、最大 Fourier 数和求解步数。
- 算法：单元中心有限体积；界面扩散系数取调和平均；时间用后向 Euler；三对角带状方程求解。
- 适用域：一维、无体源项、分段常数 `D(t,x)>0`、3～200网格、最多5000时间步；浓度单位在一次调用中一致。
- 失败：网格/数组长度不一致、扩散系数非正、时间剖面未覆盖总时长、边界值缺失、步数超限、非有限解或守恒失败。
- 重叠/依赖：可消费 C002 的扩散系数；与旧 C003 在常 D、近似半无限域、恒表面浓度条件下重叠，但计算域和边界能力不同。
- 独立验证：零通量总库存守恒；均匀初值在零通量下保持不变；与半无限误差函数解析解比较；离散方程质量闭合。

### C005：晶粒长大动力学

- 科学作用：用 `D^n-D0^n=∫K0 exp[-Q/(RT)]dt` 计算分段等温历程后的平均晶粒尺寸。
- 输入：初始晶粒直径、指数 `n`、指前因子 `K0`、激活能、温度-时长分段、参数来源和版本。
- 输出：最终直径、各段历程、累计长大项、总时间和代回残差。
- 适用域：正常晶粒长大、各向同性平均尺寸、无异常晶粒长大/钉扎突变；所有材料参数必须由调用者提供。
- 失败：非正尺寸/指数/指前因子/温度，负激活能，空温程或非有限输入。
- 重叠/依赖：与 C001 共用 Arrhenius 温度项，但输出是组织尺寸；可作为后续组织-性能工具上游。
- 独立验证：单段闭式解、分段长大项可加性、零激活能退化、公式回代残差。

### C006：球形颗粒缩核反应

- 科学作用：按膜传质、界面化学反应和产物层扩散串联阻力求球形非多孔颗粒转化率。
- 输入：颗粒半径、固体摩尔密度、气相反应物浓度、每摩尔气体A对应的固体B化学计量数、时间及可选的膜传质系数/表面反应常数/有效扩散系数。
- 输出：转化率、未反应核半径、三类时间贡献、完全转化时间、主控阻力和求根残差。
- 适用域：等温、拟稳态、球形、恒定外部气相浓度、加成反应时间近似；至少启用一种阻力。
- 失败：物性非正、三种阻力均未启用、时间为负、输入超数值域。
- 重叠/依赖：与 C001 的表面反应常数存在参数上下游关系；与后续颗粒反应数值模型在输出转化率上重叠。
- 独立验证：三种纯控制极限闭式反演、`t(X)` 单调、端点 `X=0/1`、二分求根残差。

### C007：抛物线氧化动力学

- 科学作用：按 Wagner 厚膜扩散控制的技术抛物线律计算单位面积增重和等效氧化层厚度。
- 输入：温度、时间、抛物线速率常数、初始增重、氧化物密度、氧化剂在氧化物中的质量分数、参数来源和版本。
- 输出：单位面积增重、平方增量、等效氧化层厚度、瞬时增重速率和公式残差。
- 适用域：致密、附着、单层等效氧化皮的厚膜扩散控制；速率常数必须与给定温度/气氛一致。
- 失败：速率常数/密度/质量分数非法、时间为负；薄膜、失稳氧化、剥落或线性控制应返回不适用而非外推。
- 重叠/依赖：和 C001 共用温度相关速率参数思想；可作为后续炉壁氧化损耗/寿命模型的原子上游。
- 独立验证：`(Δm/A)^2` 对时间线性、零时刻恢复初值、厚度质量换算、公式回代残差。
