## 3. 共用工程契约

### 3.1 注册与身份

- 每项继承`BaseModelTool`，实现独立`invoke()`。
- `count_eligible=True`和`qualification_status="qualified"`只能随真实实现同时提交。
- function名称必须唯一、长度不超过64字符，`additionalProperties=false`。
- `tool_uid`通过新的增量交叉映射资产固定，建议版本：`tool_catalog_crosswalk_v14.json`。
- 交叉映射统一使用`mapping_status="extension"`、`catalog_coverage=false`，不得伪装成原目录同编号覆盖。
- 运行时`relations`只能指向本波实施时已经注册的工具；对未来C012、D019、G003等候选的关系只写入蓝图说明，待目标工具注册后再增量登记，避免资格闸门因悬空关系失败。

### 3.2 错误契约

仅返回统一标准错误码：

- `INVALID_INPUT`：字段缺失、类型错误、数组长度不一致、非有限数值；
- `UNIT_MISMATCH`：输入声明单位或基准不一致；
- `OUT_OF_DOMAIN`：物理域、模型假设或相关式适用域不满足；
- `REACTION_NOT_BALANCED`：A011所得候选解不能满足元素/电荷守恒；
- `MODEL_NOT_APPLICABLE`：A011计量矩阵无唯一一维正零空间；
- `DIVISION_BY_ZERO`：输入使显式分母为零且不能以物理边界处理；
- `NUMERICAL_ERROR`：求根、指数或线性代数结果非有限/残差超阈值。

禁止新增未登记错误码。质量闭合类失败使用`OUT_OF_DOMAIN`或`NUMERICAL_ERROR`，不得返回会被归一化为`INTERNAL_ERROR`的私有代码。

### 3.3 结果与来源

每项必须：

- 返回公式版本/算法版本；
- 返回关键中间量和独立残差，不能只返回最终单值；

## 4. A011 反应计量系数求解

### 4.1 科学目标

给定反应物和产物化学式，构造元素—物种计量矩阵，求解满足元素守恒和可选电荷守恒的最小正整数计量系数。

与A006区别：

- A006校验调用者已经提供的反应系数；
- A011主动求解未知系数；
- A011输出必须可以转交A006独立复核，两项不是别名或展示包装。

### 4.2 输入Schema

| 字段 | 类型/单位 | 规则 |
| --- | --- | --- |
| `reactants` | array | 1～20项；每项含唯一`formula`和可选整数`charge` |
| `products` | array | 1～20项；每项含唯一`formula`和可选整数`charge` |
| `include_charge_balance` | boolean/1 | 默认`false`；为真时所有物种必须显式给出电荷 |
| `max_denominator` | integer/1 | 默认10000，限制有理数恢复复杂度 |

首版不处理电子、同位素、点缺陷或变量化学计量；中性水合物沿用A002既有解析语法。

### 4.3 输出Schema

- `reactant_coefficients`、`product_coefficients`：最小正整数数组；
- `balanced_reaction`：规范化反应式；
- `element_residuals`：逐元素整数残差；
- `charge_residual`：电荷残差，未启用时为`null`；
- `nullity`：计量矩阵零空间维数；
- `gcd_is_one`、`passed`、`algorithm_version`。

### 4.4 算法与边界

- 使用`fractions.Fraction`进行精确高斯消元/零空间求解，避免浮点SVD把近似零误认成守恒。
- 反应物列取正、产物列取负；解向量经符号统一、分母最小公倍数和全局最大公约数约简。
- 零空间维数不是1、不能得到所有物种严格正系数、左右元素集合不同或系数超限时失败关闭。
- 复杂氧化还原反应需要显式电荷时，未提供电荷不得隐式猜测价态。

### 4.5 验证

正常：

1. `Fe + O2 -> Fe2O3`得到`4,3,2`；
2. `C2H6 + O2 -> CO2 + H2O`得到`2,7,4,6`；
3. `KMnO4 + HCl -> KCl + MnCl2 + H2O + Cl2`得到`2,16,2,2,8,5`。

边界/失败：

1. `C + O2 -> CO2`得到全1系数，并返回边界提示；
2. `C + O2 -> CO + CO2`零空间不唯一，返回`MODEL_NOT_APPLICABLE`；
3. `Fe -> Cu`左右元素集合不一致，返回`REACTION_NOT_BALANCED`。

独立验证：把A011输出组装为A006输入，逐元素残差必须严格为0；所有系数最大公约数必须为1。

## 5. C011 传递过程无量纲数

### 5.1 科学目标

由显式流体物性和特征尺度统一计算`Re`、`Pr`、`Sc`、热/质`Pe`、运动黏度和热扩散率，并返回恒等残差。

公式：

```text
Re = ρuL/μ
Pr = cp μ/k
Sc = μ/(ρD)
Pe_heat = Re·Pr = ρ cp u L/k
Pe_mass = Re·Sc = uL/D
ν = μ/ρ
α = k/(ρ cp)
Le = α/D = Sc/Pr
```

### 5.2 输入Schema

`density_kg_m3`、`velocity_m_s`、`characteristic_length_m`、`dynamic_viscosity_pa_s`、`specific_heat_j_kg_k`、`thermal_conductivity_w_m_k`、`diffusivity_m2_s`。

除速度允许为0外，其余均必须为有限正数。首版只接受SI输入，不执行隐藏单位换算。

### 5.3 输出与关系

输出`Re/Pr/Sc/Pe_heat/Pe_mass/Le`、`kinematic_viscosity_m2_s`、`thermal_diffusivity_m2_s`，以及两条Péclet恒等相对残差。

关系：

- C011输出为C010和G001的上游；未来C012注册后再补运行时关系；
- 与G002同为稳定性/相似准则基础，但C011不推荐时间步；
- 区别C010：C010选择填充床关联式并输出传质系数，C011只计算通用无量纲群。

### 5.4 验证

三个正常用例分别覆盖气体、液体和等比例尺度变换；边界覆盖`velocity=0`；失败覆盖`μ=0`和非有限输入。独立性质要求两种Pe计算路径在`1e-12`相对容差内一致，且`Le=Sc/Pr`。

## 6. T003 集总热容瞬态温度

### 6.1 科学目标与公式

在`Bi≤0.1`时求解均匀温度物体在恒环境下的加热/冷却：

```text
Lc = V/A
Bi = hLc/k
τ = ρcpV/(hA)
T(t) = T∞ + (T0-T∞) exp(-t/τ)
Q(t) = ρcpV[T0-T(t)]
```

### 6.2 输入Schema

`density_kg_m3`、`specific_heat_j_kg_k`、`volume_m3`、`surface_area_m2`、`convection_coefficient_w_m2_k`、`thermal_conductivity_w_m_k`、`initial_temperature_k`、`ambient_temperature_k`、`time_s`。

物性、体积、面积和`h`必须为有限正数；温度必须大于0 K；时间非负。`Bi>0.1`返回`OUT_OF_DOMAIN`，不得静默使用集总近似。

### 6.3 输出Schema

`temperature_k`、`heat_removed_j`（带符号）、`biot_number`、`characteristic_length_m`、`time_constant_s`、`dimensionless_temperature`、`model_version`。

### 6.4 验证

正常用例覆盖冷却、加热和不同质量尺度；边界覆盖`t=0`与`Bi=0.1`；失败覆盖`Bi>0.1`和负时间。独立验证包括`t=0`、`t→∞`极限、温度单调性和显热闭合；小Bi工况可在G003未来注册后交叉验证，但本波不登记指向G003的运行时关系。

## 7. T004 多层热阻网络

### 7.1 科学目标与公式

计算一维稳态串联多层导热、接触热阻和两侧可选对流：

```text
R_layer,i = Li/(ki A)
R_contact,j = R''contact,j/A
R_conv = 1/(hA)
Q = (Ta-Tb)/ΣR
```

### 7.2 输入Schema

| 字段 | 规则 |
| --- | --- |
| `layers` | 1～50层；每层含唯一名称、`thickness_m>0`、`conductivity_w_m_k>0` |
| `area_m2` | 有限正数 |
| `hot_boundary_temperature_k`、`cold_boundary_temperature_k` | 大于0 K |
| `contact_resistances_m2_k_w` | 可选；长度必须等于层数减1；元素非负 |
| `hot_convection_coefficient_w_m2_k`、`cold_convection_coefficient_w_m2_k` | 可选有限正数；省略表示边界温度直接施加在固体表面 |

### 7.3 输出Schema

输出总热阻、带符号热流率、单位面积热流、各分项热阻、按热流方向排列的温度节点、温差闭合残差和公式版本。

### 7.4 边界与验证

- 两侧温度相等返回0热流并带边界提示；
- 单层、无接触、无对流时必须与T001严格一致；
- 交换两侧温度只改变热流符号，不改变热阻；
- 所有分项温降之和等于总温差；
- 接触热阻数量不匹配、非正导热系数或面积返回`INVALID_INPUT/OUT_OF_DOMAIN`。

## 8. D023 单种合金补加量

### 8.1 科学目标

以显式收得率计算单一目标元素的合金补加量。与未来D019区别：D023是单合金闭式原子工具，不做多合金、成本或混合整数优化；本波只把该关系写入说明，不登记指向尚未注册D019的运行时关系。

### 8.2 计算基准

支持两个明确基准：

1. `fixed_initial_bath_mass`：终点质量基准近似固定；

   `m = M(xt-x0)/(ηa)`

2. `addition_in_final_bath_mass`：合金加入量计入终点钢水质量；

   `m = M(xt-x0)/(ηa-xt)`

其中`M`为初始钢水质量，`x0/xt`为初始/目标质量分数，`a`为合金中目标元素质量分数，`η`为显式收得率。

### 8.3 输入输出

输入：`bath_mass_kg`、`initial_mass_fraction`、`target_mass_fraction`、`alloy_element_mass_fraction`、`element_recovery_fraction`、`mass_basis`。

输出：`alloy_addition_kg`、`predicted_mass_fraction`、`initial_element_mass_kg`、`final_element_mass_kg`、`recovered_element_mass_kg`、`final_bath_mass_kg`、`mass_balance_residual_kg`、`formula_used`。

### 8.4 边界与验证

- 所有分数位于`[0,1]`，合金含量与收得率严格大于0；
- 目标等于初始时返回0加入量并带边界提示；目标低于初始不适用；
- 终点计入加入质量时必须满足`ηa>xt`，否则目标不可达；
- 三个正常用例覆盖两种基准和不同收得率；边界覆盖零加入；失败覆盖不可达目标和非法分数；
- 独立验证采用结果反代质量守恒方程，残差不超过`1e-12·max(M,1)`；钢水质量同比缩放时加入量同比缩放。

## 9. E021 Boudouard反应平衡驱动力

### 9.1 科学目标

对`C(s)+CO2(g)⇌2CO(g)`计算标准平衡常数、实际反应商、实际Gibbs驱动力和同一COx分压和下的平衡气相比。

首版不自行查询现场数据或隐藏热力学常数。现有B008已经支持`C+O₂→CO₂`和`2C+O₂→2CO`两条数据库反应记录，因此E021要求显式传入这两次B008执行的结果与执行ID，并按Hess定律组合Boudouard标准Gibbs：

```text
B008：2C+O₂→2CO ─┐
                   ├→ E021：C+CO₂→2CO的ΔG°、Q与实际驱动力
B008：C+O₂→CO₂  ─┘
```

### 9.2 输入Schema

`temperature_k`、`total_pressure_pa`、`co_mole_fraction`、`co2_mole_fraction`、`carbon_activity`、`co_formation_reaction_gibbs_kj_mol`、`co2_formation_reaction_gibbs_kj_mol`、`co_formation_execution_id`、`co2_formation_execution_id`、可选`standard_pressure_pa`（默认100000 Pa）、可选平衡相对容差。

要求：

- 温度、压力、标准压力和碳活度严格为正；
- CO和CO2摩尔分数严格为正，且二者之和不大于1；
- 首版气体按理想气体处理，其他气体只通过稀释影响分压；
- `co_formation_reaction_gibbs_kj_mol`必须原样接收B008的`delta_G`，对应反应`2C+O₂→2CO`的整条反应计量基准；
- `co2_formation_reaction_gibbs_kj_mol`必须原样接收B008的`delta_G`，对应反应`C+O₂→CO₂`；
- 两次B008执行必须使用同一温度，两个执行ID均必填并通过格式校验；E021不接受无法追溯的直接Boudouard常数。

### 9.3 公式与输出

```text
ΔG°[kJ/mol] = ΔG°(2C+O₂→2CO) - ΔG°(C+O₂→CO₂)
Kp = exp(-ΔG°/RT)
Q = (pCO/p°)^2 / [aC (pCO2/p°)]
ΔG = ΔG° + RT ln Q = RT ln(Q/Kp)
```

在保持`pCO+pCO2`不变时，令`r=pCO/pCO2`、`S=Kp·p°·aC/(pCO+pCO2)`，则：

`r_eq = [S + sqrt(S²+4S)]/2`

计算指数和`RTlnQ`时必须把kJ/mol显式换成J/mol。输出`standard_reaction_gibbs_kj_mol`、`actual_reaction_gibbs_kj_mol`、`equilibrium_constant`、`reaction_quotient`、`quotient_to_equilibrium_ratio`、`direction`、`actual_co_to_co2_ratio`、`equilibrium_co_to_co2_ratio`、三个分压字段、公式版本和两个上游执行ID。

### 9.4 验证

- 构造`Q=Kp`用例，驱动力为0且方向为`equilibrium`；
- `Q<Kp`为正向气化，`Q>Kp`为逆向沉碳；
- 反代`r_eq`必须使重新计算的Q等于Kp；
- CO/CO2同比稀释时，实际比值不变但Q按分压正确变化；
- HTTP集成测试必须真实执行两次B008，再把两层执行结果传入E021，保留三个执行ID；
- 非正分压、摩尔分数和大于1、缺失上游执行ID或指数溢出分别返回`INVALID_INPUT/OUT_OF_DOMAIN/NUMERICAL_ERROR`。

## 13. 停止条件

- 工具只能通过硬编码算例或复制现有函数实现；
- A011无法保证唯一正整数解或A006复核不通过；

- function Schema不唯一、HTTP/forced调用失败或现有回归出现破坏；
- 实际合格数量小于6时仍试图报告80项。
