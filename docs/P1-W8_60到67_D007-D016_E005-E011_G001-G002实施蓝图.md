## 2. 为什么选择这7项

本波形成三条可执行链，而不是7个孤立函数：

```text
D001理论耗氧 ─┬─→ D007分段脱碳 ─→ D015炉气生成 ─→ D016氧利用率
              └──────────────────────────────→ D016

E003碳平衡 / E004氧平衡 ─→ E005氢平衡 ─↔ E011炉顶气利用率

特征尺度 ─→ G001网格计划 ─→ G002时间步校验 ─→ C103/F005数值PDE
```

D008终点碳ML和D009终点温度ML本波继续停止：当前DS042只有资料源元数据，没有可审计炉次样本、数据许可、时间切分、固定训练产物和外部验证，不能把Schema或未训练模型计入工具数。

## 3. 数据与来源边界

### 3.1 D007

D007读取现有 PostgreSQL `metallurgy_v2.element_reference` 中的C原子量；分段供氧量、脱碳氧效率和动力学上限由调用者提供，并强制附带 `parameter_source` 与 `parameter_version`。首版不导入、猜测或硬编码任何炉龄、枪位、钢种或厂级标定系数。

算法按每段计算：

```text
nu_O2/C = 0.5*(1-f_CO2) + 1.0*f_CO2
r_C,O2 = F_O2 * eta_decarb * M_C / nu_O2/C
r_C = min(r_C,O2, r_C,kinetic, m_C,remaining/dt)
```

若未提供动力学上限，则该段仅为供氧控制；工具必须明确返回实际控制模式。氧枪位置、乳化面积和炉气分析只有先被外部已验证模型转换为显式效率/速率上限后才能输入，首版不假装直接建模这些变量。

主要科学依据：[Dogan、Brooks、Rhamdhani，ISIJ International 51 (2011) 1102](https://doi.org/10.2355/isijinternational.51.1102)。该文支持BOF脱碳同时受供氧/气相传质和界面反应约束；本工具只实现透明的约束积分骨架，不复制论文或工厂标定参数。

### 3.2 D015/D016

D015以D007输出的分段脱碳 `kmol C` 和显式 `CO2` 分率为输入：

```text
n_CO2=f_CO2*n_C
n_CO=(1-f_CO2)*n_C
n_gas=n_CO+n_CO2
V=n_gas*R*T/P
```

标准体积固定采用273.15 K、101325 Pa；气体常数采用SI/CODATA值并在来源记录中声明版本。D016只接受规范化的有用耗氧分项、实供氧和可测损失分项，拒绝有用耗氧或已知损失超过实供氧，避免把D001与D015的同一碳耗氧重复相加。

### 3.3 E005/E011

E005对输入、输出物流中每个中性化学式调用A002同一解析器，按化学式中的H计量数换算 `kmol H atoms`，输出残差、闭合率和指定炉顶气流股的H2/H2O指标。E011不做总平衡，只处理按时间递增的炉顶气组成序列：

```text
eta_CO = x_CO2/(x_CO+x_CO2)
eta_H2 = x_H2O/(x_H2+x_H2O)
```

两者输出重叠但计算目标不同：E005审计全流程氢原子闭合，E011比较炉顶气利用率及其变化。利用率定义依据：[Barrett等，ISIJ International 62 (2022)](https://doi.org/10.2355/isijinternational.ISIJINT-2021-574)。

### 3.4 G001/G002

G001要求调用者显式给出一个或多个需要解析的物理尺度及最低单元数，按最严格尺度产生粗/中/细三网格计划；可选输入三个网格上的同一QOI，计算观察阶、Richardson外推和细网格GCI。依据为[NASA TM-2000-209946](https://ntrs.nasa.gov/api/citations/20000054672/downloads/20000054672.pdf)和[NASA/TP-2016-219422](https://ntrs.nasa.gov/api/citations/20160013550/downloads/20160013550.pdf)。没有三网格QOI时只给网格计划，不伪造GCI。

G002只适用于显式一阶迎风对流与显式中心扩散：

```text
CFL_sum = dt*sum_i(|u_i|/dx_i)
Fo_sum  = dt*sum_i(alpha_i/dx_i^2)
dt_max  = min(CFL_target/sum_i(|u_i|/dx_i), Fo_target/sum_i(alpha_i/dx_i^2))
```

至少启用一种机制；隐式格式、高阶格式或非结构网格返回 `MODEL_NOT_APPLICABLE`，不套用错误的通用稳定性结论。CFL理论依据为[Courant、Friedrichs、Lewy原文英译](https://galton.uchicago.edu/~lekheng/courses/302/classics/courant-friedrichs-lewy.pdf)。

## 4. 契约摘要

### D007 脱碳速率模型

- 必填：`initial_metal_mass_kg`、`initial_carbon_mass_fraction`、`segments[]`、`carbon_to_co2_fraction`、`parameter_source`、`parameter_version`。
- `segments[]`：`name`、`duration_s`、`oxygen_flow_kmol_s`、`decarburization_oxygen_efficiency`，可选 `kinetic_rate_limit_kg_s`。
- 输出：逐段起止时间/碳量/碳分数、供氧与有效耗氧、供氧上限、动力学上限、实际速率、控制模式，总脱碳量、终点碳、C/O守恒残差及参数身份。
- 失败：分段结构/名称/数值非法，重复段名，碳分率或效率越界，剩余金属质量非正，数据库原子量不可用。

### D015 炉气生成量

- 必填：`decarburization_segments[]`、`gas_temperature_k`、`gas_pressure_pa`；可选D007上游执行ID。
- 每段：`name`、`duration_s`、`carbon_removed_kmol`、`carbon_to_co2_fraction`。
- 输出：CO/CO2 kmol及摩尔分数、实际/标准总体积、分段平均流量、耗氧量、碳计量残差。
- 失败：段为空/重复/时间非正，组成越界，温压非法，非零碳量但零气量。

### D016 氧利用率计算

- 必填：`actual_oxygen_supply_kmol`、`useful_oxygen_components_kmol_o2`；可选 `measured_loss_components_kmol_o2`、上游执行ID映射。
- 输出：有用氧总量/分项占比、已知损失、未计量损失、总损失、利用率和氧量闭合残差。
- 失败：对象为空、分项负数/非有限、分项和超过实供氧、同名来源含义冲突。

### E005 高炉氢平衡

- 必填：`basis`、`input_streams[]`、`output_streams[]`、`top_gas_stream_name`；每条物流含唯一名称和 `species_kmol` 对象。
- 输出：逐流/逐物种H原子量、输入输出H、残差/闭合率、H2当量、炉顶气H2/H2O和利用率。
- 失败：化学式非法、物种量负值、找不到炉顶气流股、炉顶气无H2/H2O、时间基准混用。

### E011 CO/CO2及H2/H2O利用率

- 必填：`composition_basis`、`gas_samples[]`；每个样本含 `time_s` 和摩尔/体积分数组成。
- 输出：各样本ηCO/ηH2、最新值、首末变化和趋势方向。
- 失败：时间不严格递增、组成和超过1、组分负数、所有样本均无有效分母。

### G001 网格尺度估计

- 必填：`domain_lengths_m`、`resolution_drivers[]`；可选 `refinement_ratio`、三项 `qoi_values_coarse_to_fine`。
- 输出：限制尺度、推荐网格宽度、三网格各轴单元数/总单元数；有QOI时返回观察阶、外推值、GCI。
- 失败：轴/驱动为空或重复，尺度/单元数非法，QOI非单调收敛、差值为零或细网格QOI为零。

### G002 时间步与CFL校验

- 必填：`cell_sizes_m[]`、`time_step_s`、`advection_scheme`、`diffusion_scheme`；启用机制时对应速度/扩散率数组必填且维数一致。
- 输出：CFL和Fourier分项/总和、各机制最大时间步、总最大时间步、限制机制和稳定结论。
- 失败：维数不一致、全部机制禁用、格式超适用域、步长/属性非法。

## 6. 验证与准入

每项必须在模型卡内有3个正常和至少2个边界/失败用例。专项独立验证至少包括：

- D007：纯C供氧计量、动力学/供氧控制切换、逐段C/O守恒与尺度线性；
- D015：CO/CO2极限、理想气体温压缩放、分段总量与流量积分；
- D016：利用率定义、分项求和、整体缩放不变性；
- E005：H2/H2O/CH4化学式计数、氢原子闭合、流股拆分不变性；
- E011：手算ηCO/ηH2、单样本与时序趋势、摩尔/体积分数等价；
- G001：限制尺度、单元数向上取整、合成二阶序列的观察阶与GCI；
- G002：一/多维CFL与Fourier手算、最大时间步边界、维数校验。

接口验收包括 `/api/v1/tools`、逐工具函数路由和 `/api/v1/experiments/run` 的forced模式。本波完成后运行专项测试和全量回归；真实外部大模型API仍不调用，隔离forced接口证明工具可被大模型编排层逐项调用。
